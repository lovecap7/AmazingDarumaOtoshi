## 1. 作業の進め方（中平の作業でのみ守る）

- **報告・途中経過・質問はすべて日本語**で書く。
- 進め方：ざっくりした指示 → 実装タスクに分ける → 迷う所・あいまいな所を質問する（はい／いいえ／自由回答）
  → タスクを直す → 要件が固まるまで質問を繰り返す → **それから** UnityMCP で実装する。
  新しい依頼でいきなり実装しない。
- **新しく作るファイルは必ず `Assets/Nakahira/` の中**（中のフォルダ構成は自由）。
- 他のメンバーのフォルダ（Assets/Inoue・Assets/Shitaka・Assets/Fujihara など）の既存ファイルは編集してよい。
- プロジェクト設定（Build Settings を含む）は変更してよい。
- **Resources フォルダは使わない・作らない**（Resources.Load も使わない）。参照はシリアライズや Addressables などで。
- ルールのせいで正攻法が使えず、とても遠回りな方法しかないときは、遠回りせずに「ルールを変えてよいか」を聞く。
- プッシュなどは中平が GitHub Desktop で行う（Claude はコミット・プッシュしない）。
- 他のメンバーのファイルを変えたときは、**ローカルプレイの動きを変えない追加だけ**にして、作業の最後に変えたファイル名を報告する（リポジトリの CLAUDE.md のルール）。
- **ネット対戦（`Assets/suehara`）には手を付けない**。ネットでも見せたい演出は末原さんにタスクを渡す。
- 演出の見た目（線・色・太さなど）は、コードで組み立てるより**プレハブやマテリアルのアセットにして、インスペクターで編集できる形**にする（中平の好み）。

## 4. プレイヤーの仕様（決定済み。聞き直さない）

コードは `Assets/Nakahira/Player`。チームメイトの試作（Inoue の Player.cs、Shitaka の BlockController）は使わず、一から作った。

- **入力**：ゲームパッドのみ。左スティック移動／A ジャンプ／X 薙ぎ払い／B ショット。カメラは全員共通の見下ろし。
- **入力とロジックの分離**：`IDarumaCommandSource` / `DarumaCommand`。`DarumaCommand.Move` はワールドの XZ（カメラ変換は `DarumaInputHandler` 側）。
  CPU・ネット対戦はこのインターフェースを実装するだけでよい。`DarumaPlayer.SetCommandSource` で実行中に差し替えられる。
- **オンライン**：Netcode for GameObjects を予定しているが後回し。
- **拾う**：空中で落下中（物理ステップ前に vy<0）に触れた積み木は、どんな状態・速さでも拾える（ダメージなし。当たった場所は問わない）。
  積み木は接地判定から除外。地上で横から当たったらダメージ。
- **積む**：落ちている積み木に着地 → 一番下に追加。最大 10 段、超えたら一番上（古いもの）を落とす。高いほど遅い。
- **股抜きショット**：後ろからハンマーで最下段を前へ打ち出す。まっすぐ滑り、壁で反射、奈落へ落ちる。
- **飛んでいる積み木**：減速する。`TumikiBlock.IsHarmful`（Speed ≥ HarmlessSpeed）で攻撃判定の有無が分かれる。
  攻撃判定のない飛んでいる積み木は、壁で反射・他の積み木と弾性衝突（壊れない）・キャラクターに当たると反射（押さない。キャラの質量 20）。
  ハンマーからは落ちている積み木と同じ扱い。StopSpeed を下回ると落ちている積み木に戻る。
- **薙ぎ払い**：右 → 左の横振り。ハンマーが相手の方向を通り過ぎたときに当たる。落ちている積み木はその方向へ飛ぶ。
  飛んできた積み木：先端で捉えると左へ、根元だと右へ。打ち返しの弾速 = 基本 10 × 1.25^打ち返し回数（連鎖でも回数を引き継ぐ）。
  届く距離 ×1.5（HitReachScale）。打ち返した中平は 0.5 秒その弾に当たらない（ReturnImmunityTime）。
- **連鎖**：飛んでいる積み木が積み木（タワーの段も含む）に当たる → 当たられた方が中心同士を結ぶ線の向きに飛ぶ（ビリヤード。速さ v·n）。当てた方は壊れる。
- **脱落**：頭だけの状態で弾かハンマーに当たる、または奈落に落ちる → キャラクターが消えて幽霊が出る。
  - 幽霊：浮く・壁は通れない・ジャンプ／積む／ショットなし・当たり判定なし（弾がすり抜ける）・ゆっくり薙ぎ払う（0.5 秒）・飛んでくる積み木は打ち返せる・頭だけの生存者を脱落させられる。
  - 幽霊が生存者にダメージを与える（積み木を飛ばして・連鎖で当てても可。打ち返した人に手柄が移る）→ 他の全員から一番遠い出現地点に頭だけで復活、1.5 秒無敵。
  - 2 人以上いて生存者が 1 人以下になったら試合終了。終了は復活より優先。
- **ヒットストップ**（スマブラ風）：薙ぎ払いが当たったとき・ショットで、攻撃した側・弾いた積み木・直接叩かれた相手だけがスローになる（全体の timeScale は使わない）。
  震えは見た目だけ（`Visual` 子オブジェクトの `HitStop`。当たり判定は動かない）。値は HammerParams（幽霊は弱め）。スロー中のジャンプは先行入力として保持。
  積み木同士・積み木とタワーの衝突もヒットストップ（速さに応じる。値は TumikiParams）。壊れる側はヒットストップが終わってから砕ける。
  打ち返しのヒットストップは 1 回ごとに ×1.6、上限 2 秒（Lethal League 風）。
- **エフェクト**：積み木が動いている間は煙の軌跡、攻撃判定があるときは炎のオーラ（Shuriken）。
- **調整値は ScriptableObject**（`Assets/Nakahira/Player/Params`）。使うたびに読むので再生中に変えても反映される。
  - `HammerParams`：キャラクターごと（`Hammer_Default`・`Hammer_Ghost`）。中平はキャラごとにハンマーの差をつけたい。
  - `JumpParams`：全キャラ共通（キャラごとの差はつけない）。
  - `TumikiParams`：共通。`GhostParams`：幽霊。

**進み具合（2026-11-09 時点）**
- 実装済み（詳しくは設計メモの各節）
  - 状態：積む・逃げる・殴る・撃つ・攻めに行く・待つ・遊ぶ（8 段以上で攻め寄りになる）。
  - とっさの反応（`CpuReflex`）：ジャンプ乗り・打ち返し・ジャンプ避け。ジャンプ避けは跳びながら動く（`CpuDodgeMove`、DodgeMoveChance 0.8）。
  - 縁で踏ん張る（`CpuEdgeGuard`）。風や押された勢いで落ちないようにする。
  - ギミック：せり上がり塀・扇風機はナビメッシュで切り抜く（`CpuGimmickObstacle`）。移動床には乗って移動する（`CpuMovingFloors` / `CpuRide`）。
    移動床はステージ専用の作りではない。どのステージでも、止まる地点のそば（縁から 1.2m・高さ差 0.5m 以内）に床があれば乗り場ができる。テストは DebugStage23 だけ。
  - **幽霊のときの動き**（`CpuGhost.cs`。設計メモ §5.4）。`DarumaCpu` は体がなく幽霊がいるときに `CpuGhost` で動かす。

    - 攻撃：毎フレーム最初に判定。自分の動きも含めて当たるかを予測して振る（反応の遅れ・早振りあり）。
    - 弾いて当てる：相手の近くの積み木の後ろ側に回り、近づいたら入力 0.2 でゆっくり寄って弾く。
    - ワープゲート：近道になるときだけ使う（使ったあと 1 秒は再判定しない、1.5 秒たどり着けなければあきらめる）。
    - `DarumaGhost.cs` に読み取り用の `Hammer`・`MoveSpeed`・`Radius` を足した。
  - **セレクト画面から試合に入ると `DarumaCpu` が出る**。`DarumaMatch.CreatePlayer` が `m_settings.CpuParamsFor(e.cpuLevel)` を使い、
    CpuParams があれば `DarumaCpu`、なければ今までの `CpuDarumaInput`。
  - **強さは 3 段階**（チームで 1〜9 から減らすことになった）。セレクト画面も 1〜3。
    - CpuParams：`Assets/Nakahira/Cpu/Params/` の `0_Cpu_Strong`（つよい＝元の CPU）・`1_Cpu_Normal`・`2_Cpu_Weak`（中平が名前を付け直した）。

    - 対応：`MatchSettings.asset`（`Assets/Fujihara/Resources/`）の `cpuParams` = [よわい, ふつう, つよい]。`CpuParamsFor(level)` はそのレベル以下で一番近いものを返す。

  - **殴り合いのジャンプ避けを人並みにした**（テストプレイで「最初のハンマーを必ずジャンプで避けられるのがストレス」と言われたため。`CpuMeleeState.cs`）。

      ハンマーが自分の所をもう通り過ぎていたら跳ばない（`CanStillDodge`）。
    - 読みジャンプ（新規）：相手が間合い・ハンマーの届く角度にいて、地上でいつでも振れるときに、振られる前に跳ぶ。
      - 間合いに入った瞬間：`ReadJumpOnEnterChance`（つよい 0.5／ふつう 0.3／よわい 0.15）で、0.05〜0.2 秒後に跳ぶ。

## 6. 演出（2026-11-06）

中川さんの演出の部品（`Nakagawa.EffectMeshes`・`CameraFocusTarget` など）は読むだけで使い、中川さんのファイルは変えていない。

### 幽霊の出現演出（スプラトゥーンの復活風）
- 脱落すると、魂（青白い人魂）が上へ飛んで画面の外へ出る → 待つ間、出る場所に印（輪と円）が出る → 魂が上から降ってきて着地 → 光って幽霊がポンと出る。
  全体で約 2 秒（Time.deltaTime 基準）。奈落に落ちたときも同じ（落ちた位置から飛ぶ）。
- 中川さんの今の脱落演出はそのまま残し、その上に足している。カメラワークは変えていない。
- 幽霊は脱落と同時に作って隠しておき（`DarumaGhost.BeginAppear`）、演出が終わったら見せて動けるようにする（`FinishAppear`）。
  こうしておくと HUD・音・積み木の出現など、幽霊がいる前提のほかの人の仕組みが今までどおり動く。
  演出中の幽霊は `DarumaGhost.Active` に入らず、`Update` も止まる（CPU も動かない）。
- ファイル
  - `GhostAppearEffect.cs`：演出の流れ（上がる → 待つ → 落ちる → 着地）。`DarumaMatch.SpawnMatchGhost` から呼ぶ。
  - `GhostSoulVisual.cs`：人魂の見た目（しずく形の芯と光・軌跡・点光源）。復活演出と共用。
  - `GhostAppearParams.cs` / `GhostAppear_Default.asset`：時間・高さ・色・大きさなど全部の調整値。`DarumaGhost.prefab` に設定済み（ネット用のバリアントも引き継ぐ）。
- ネット対戦では出ない（クライアントでは `DarumaGhost` が止まっているため）。末原さんに任せる。

### 幽霊の復活演出（魂の移動）
- 復活したとき、魂が幽霊の位置から出現地点まで弧を描いて飛ぶ（0.7 秒）。着いてから中川さんの今の復活演出（光の柱）が始まる。
  自分のキャラがどこに出るか分かりやすくするための視線誘導。カメラも魂を映す（`CameraFocusTarget`）。
- 幽霊からの復活だけ（ストック・タイムの復活には付けていない）。
- 移動時間は `DarumaMatch` の `m_reviveTravelTime`（0 にすると今までどおり即復活）。弧の高さなどは `GhostAppearParams` の「復活」。
- `DarumaMatch` の出現待ちの仕組みの中に「移動中」の段階を足した（`ReviveFromGhost`・`Appearing.travelLeft`）。
  移動中も試合では出場中として数える。移動が始まると `PlayerReviveTraveling` イベントが出る。
- ファイル：`GhostReviveSoulEffect.cs`。

### ハンマーのトレイル・向き
- 薙ぎ払いの間だけ、ハンマーを柄を軸に 90° ひねる（頭の長い向きが振る向きとそろう）。`DarumaHammer.m_sweepRoll`。
  ショット・待機の向きは変えていない。当たり判定には影響しない。
- 振っている間（薙ぎ払い・ショット）、ハンマーの頭から細い線が出る。
  - プレハブ：`Assets/Nakahira/Player/Effects/HammerTrail.prefab`（白）と、そのバリアント `HammerTrail_Ghost.prefab`（青白く薄い）。マテリアルは `HammerTrail.mat`。
  - 太さ・残る時間・色はプレハブの `TrailRenderer` で編集する。
  - どのプレハブを使うかは `HammerParams.TrailPrefab`（空なら出さない）。キャラごとに変えたいときはバリアントを作って割り当てる。
  - `DarumaHammer` が再生時にプレハブから作る。ハンマーの子にはしない（待機位置へ戻るときに線が引っ張られないように）。
  - コードだけで効くので、ゆるべさんのキャラ・末原さんのネット用も含め、ハンマーのプレハブは変えていない。
