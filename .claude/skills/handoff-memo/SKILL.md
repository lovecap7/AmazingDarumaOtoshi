# 引き継ぎメモの更新（中平専用）

中平以外のメンバーから頼まれたときは使わず、そのことを伝える。

## 手順

1. `AmaizingDarumaOtoshi/Assets/Nakahira/引き継ぎメモ.md` を全部読む。
2. 今の状態を調べる（推測で書かない）。
   - この会話でしたこと・決まったこと・分かったこと。
   - `git log --oneline -15` と `git status` で、前回の更新から増えた変更。
   - CPU の作業なら `AmaizingDarumaOtoshi/Assets/Nakahira/Cpu/CPU設計メモ.md` の見出し・「未決」・「実装の順番」。
   - 気になる所はコードを開いて確かめる（例：どの経路でどの CPU が出るか）。
3. メモを直す。
   - 該当する節（例：「5. CPU の状況」の「進み具合（日付 時点）」「まだの所」「知っている不具合」「次にすること」）を **書き換えて最新にする**。古い記述は消すか直し、同じことを二重に書かない。
   - 日付は今日の日付（絶対日付）に更新する。
   - 新しい分野の作業なら、節を足す。
   - 「1. 作業の進め方」「3. 用語」「4. プレイヤーの仕様」は、中平が決め直したときだけ変える。
   - 書き方：日本語・短い箇条書き・ファイル名やクラス名は `コード` で書く。詳しい仕様は設計メモに任せ、ここには要点と置き場所だけ書く。
4. ほかのファイルは変えない（設計メモに書くべきことがあれば、書いてよいか聞く）。
5. 中平への報告（日本語）：何を足した・直した・消したかを短く。コミット・プッシュはしない。
