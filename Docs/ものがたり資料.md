# 1. 全体像

## 1.1 作品とテーマ

弱小のだるま落とし部が、新入部員を迎えながら全国制覇を目指す青春ストーリー。

- **積み上げる**：積み木を積む＝仲間との信頼・練習の積み重ね。
- **一撃入魂**：あかだるの部訓。溜めたものを一撃に込める。
- **まっすぐ**：あかだるの「まっすぐな一撃」と、へびだるの「曲がる弾」の対比。
- **二つで足りる**：だるきんぐの「王冠は二つあれば足りる」。仲間を持たない王の孤独。
- **片目のだるま**：全国制覇したら、もう片方の目を入れるという先代からの願掛け。物語全体の象徴。

## 1.2 あらすじ（ネタバレ込み）

七転高校だるま落とし部に、おにぎりにつられてきだるが入部する。主将あかだる、副主将あおだる、分析担当みだるに迎えられ、きだるはみだると練習試合をする。

夏の地区大会決勝、あおだるは巌高校のいわだると対戦。飛ばすのが苦手なあおだるは、ハンマーで打ち返し、走ることで勝利する。祝勝のなか、いわだるは「去年の準決勝、自分の前に突然壁が現れた」と語る。会場の図面には、そんな壁は記録されていない。

全国大会準決勝、あかだるは中学時代のチームメイト・へびだると再会する。へびだるの弾は左右に曲がる。苦しみながらも、あかだるはまっすぐな一撃でへびだるを破る。へびだるは「ボクにも事情がある」「『落とし手』って言葉だけは覚えといて」と告げる。

全国大会決勝。相手は王者だるきんぐ、そして先に待っていたいわだるとへびだる。だるきんぐは「王冠は二つあれば足りる。余には、それ以上は要らぬ。……積み上げる仲間も、おらぬからな」と語る。あかだるは仲間が積んでくれたものを一撃に込め、全国制覇を成し遂げる。だるきんぐは「余に、おにぎりを一つ」とだけ答える。

全国制覇の夜、部室のノートの最後のページに文字が増えている。そして――「積み上がったな。……ならば、落とす番だ」。

## 1.4 章選択の仕様

- 章は `order` の小さい順に、**上から**並ぶ（序章が一番上）。
- 状態表示：
  - 未解放：灰色＋「ロック（前の章をクリアで解放）」
  - 解放済み：水色＋「あそべる」
  - クリア済み：緑＋「クリア済み（Aで再プレイ）」
- 解放条件は直前の章のクリア：
  - 序章：最初から遊べる
  - 第1章：序章クリア
  - 第2章：第1章クリア
  - 最終章：第2章クリア
- 章をクリアすると、その章を `requiredChapter` に持つ章が自動で解放される。

## 1.5 共通の進行フロー

```
章選択
  ↓
AllStages を読み込み、stageId のステージへ
  ↓
カットシーン（A：つぎへ／B：スキップ）
  ↓
会話（前）（A：つぎへ／B：スキップ）
  ↓
暗転 → カウントダウン
  ↓
チュートリアル（章による。無い章もある）
  ↓
試合
  ├─ 勝利 → リザルト → 実績カード → 会話（後） → 横断幕 → だるま新聞
  │        → 章クリア保存 → クリア実績 → エピローグ（最終章のみ） → 章選択へ
  └─ 敗北 → KO演出 → 敗北台詞 → 同じステージを読み直してリトライ
```

## 1.6 操作

### カットシーン

- A：次のカットへ
- B：ムービー全体をスキップ
- 章クリア済みの再プレイでBを押した場合、カットシーンだけでなく**会話（前）も**スキップされる。
- 初回プレイでBを押した場合、カットシーンだけをスキップし、会話（前）は表示される。

### 会話

- A：文字送りを最後まで表示（同じ押下では次へ進まない）。もう一度Aで次の行へ。
- B：その会話の残りをスキップ。
- ト書き（話者なし）は小さめ・薄い文字で表示される。

### 試合中

- 左スティック：移動
- A：ジャンプ
- X：ハンマー
- B：積み木を飛ばす
- L／Y：必殺技（ゲージ満タン時）

## 1.7 勝利・敗北・リトライ

### 勝利

1. リザルト文字を約2秒表示
2. 解除された実績カードを表示
3. 会話（後）を表示
   - 序章：部室（夕方）
   - 第1章：ステージ（夕方）
   - 第2章：全国大会会場（夕方）
   - 最終章：決勝の舞台（夕方）
4. 最終章は横断幕「全国制覇！ だるま落とし部」を掲げる
5. だるま新聞を表示
6. 章クリアを保存（`Story.Clear.<章ID>`）＋次章を解放
7. クリア実績を表示
8. 最終章のみエピローグ（控室 → 部員名簿 → だるま人形 → ロゴ）を表示
9. 章選択へ戻る

### 敗北

1. 赤い閃光＋「やられた…」
2. 章データの `defeat` を表示
3. 同じステージを読み直してリトライ
4. リトライ時はカットシーン・会話（前）を飛ばし、チュートリアルは到達ステップから再開
5. 一度見た初回イベント（掛け合いなど）は繰り返さない

### リトライで保持される状態

| 状態 | 内容 |
|---|---|
| `IntroPlayed` | 会話（前）を見たか。リトライでは出さない |
| `TutorialStep` | 完了したチュートリアルステップ。続きから再開 |
| `MatchStartPlayed` | 試合前の一言を見たか。リトライでは出さない |
| `AwakeningDone` | 序章の必殺技チュートリアルを終えたか |
| `LastStandPlayed` | 第2章以降の必殺技イベントの掛け合いを見たか |
| `YellowExtraPlayed` | きだるの黄色増殖の掛け合いを見たか |
| 章ごとのイベントキー | 打ち返し・壁破壊・連鎖・CPU掛け合い・脱落台詞など |

## 1.8 セーブ・解放・実績

### セーブ

- 章クリア：`Story.Clear.<章ID>` に1を保存（だるま新聞まで見た時点）
- 章解放：`Story.Unlock.<章ID>` に1を保存
- 解放演出を見たか：`Story.UnlockSeen.<章ID>`
- 保存先は `PlayerPrefs`

# 5. 実装メモ

## 5.1 章データの主な項目

`StoryChapter`（`StoryData.cs`）の主なフィールド。

|---|---|
| `id` / `order` / `title` / `subtitle` / `hiddenTitle` | 章の識別・並び・表示名 |

| `stageId` / `sceneName` | 読み込むステージ |
| `playerCharacter` | 操作キャラのID |
| `rules` | モード・ストック・時間・CPU必殺技・覚醒・ゲージ表示・CPU積み木上限 |
| `cpu` | 相手キャラ・レベル・ストック・表示名 |
| `speakers` | 話者ID・表示名・色 |

| `cpuTaunts` / `cpuTauntOnShot` | CPUの掛け合い |
| `yellowExtra` | きだるの黄色増殖の掛け合い |

| `epilogue` | 最終章のエピローグ |
| `newspaper` | だるま新聞 |

## 5.2 章を追加するとき

1. `Assets/Yurube/Story/Resources/Story/` に `<章ID>.json` を追加する。
2. `id`・`order`・`title`・`requiredChapter`・`stageId`・`playerCharacter` を設定する。
3. `speakers` に話者を定義する（既存キャラは流用可）。
4. `before` / `after` / `defeat` / `tutorial` / `cpu` を書く。
5. 章選択は `Resources/Story` を全部読むので、UI側の追加作業は不要。
6. 章クリア実績を追加する場合は `AchievementCatalog.cs` に `storyChapter` を指定した定義を足す。

## 5.3 チュートリアルの条件

| `condition` | 判定 |
|---|---|
| `DialogueDone` | 説明を読んだら次へ |
| `MoveAndJump` | 移動＋ジャンプ |
| `Stack` | 積み木を指定数積む |
| `Attack` | ハンマーかショット |
| `Reflect` | 飛んできた積み木をハンマーで打ち返す |
| `Chain` | 相手に当てたあと、積み木→積み木の連鎖を起こす |

- `cpu` にキャラIDを書くと、そのステップの間だけそのCPUが動く。`all` で全員、空で全員停止。
- チュートリアル中の停止CPUは、当たり判定も消える。

## 5.4 初回イベントのキー

`StorySession` の `HasEvent` / `MarkEvent` で、章ID＋種類のキーを保存している。リトライしても同じ掛け合いは繰り返さない。

例：

- `<章ID>.reflect`：打ち返し初回
- `<章ID>.wall`：岩の壁破壊初回
- `<章ID>.chainFirst`：連鎖初回
- `<章ID>.chainHint`：連鎖ヒント
- `<章ID>.taunt.<キャラID>`：CPU掛け合い
- `<章ID>.out.<キャラID>`：脱落掛け合い
- `<章ID>.lastTwo`：残り2人の掛け合い
- `<章ID>.startLines`：開始直後の掛け合い

## 5.5 現在の注意点・要確認

1. **序章の `awakening` 3行は未使用**
   - 現在の序章はゲージチュートリアル（`PrologueFullSpecialPrompt`）で進むため、`StoryMatchDirector.Awakening()` が呼ばれない。
   - `prologue.json` の `awakening` はレガシー。使うなら序章のフローに組み込む必要がある。

2. **第1章は必殺技が使えない**
   - `gaugeFromStart: false` かつ覚醒イベントが無いため、`SpecialInput.StoryLocked` が解除されず、ゲージも表示されない。
   - 仕様として意図しているか要確認（「見せ場まで隠す」想定なら、第1章にも覚醒イベントが必要）。

3. **ステージIDが仮**
   - `DebugStage31` / `DebugStage46` / `DebugStage47` は仮。本番ステージに差し替える際は `stageId` を変更する。

4. **操作は1人＋CPUのみ**
   - `StoryLauncher` は「プレイヤー1人＋章データのCPU」だけを登録し、`rules.teams = false` にしている。
   - 部員（あおだる・みだる・きだる）は会話に登場するが、試合には参加しない。
   - 第1章・第2章・最終章は、プレイヤー1人 vs CPU3体のフリーフォー。

5. **キャラデータの表記**
   - あかだる・あおだる・いわだるの `passiveName` / `specialName` は `～～～` のまま。
   - 実際の能力名は `Script/` 側のコメント・カットイン名で確認できる。

6. **章選択の並び**
   - 2026-11-19に「序章が上、最終章が下」へ変更。`StoryChapterSelect.Build()` の配置と `Update()` の上下入力をセットで直している。
