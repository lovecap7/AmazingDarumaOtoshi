# ミニゲーム由来のギミック案

Minecraft の有名サーバーにあるミニゲームのギミックを元にしたステージの案です。まだ案の段階で、実装していません。

## 方針

- 本番ステージ(Stage01〜24)は「家の中の小物の上で戦うミニチュア」の世界観。
  Stage21(氷割りゲーム)の氷がずれて見えるのは、家の中の物ではなく「ゲームの素材」に見えるため。
- ギミックの仕組みは借りて、見た目は「同じ動きをする家の中の物」に置き換える。

## 前提にした試合のルール(中平さんの担当)

- 積み木の段数が体力。高く積むほど遅い。
- 脱落すると幽霊になる。幽霊が生存者にダメージを与えると、頭だけで復活し、1.5秒無敵。
- 幽霊は積み木を打ち返せる。当たり判定はない。

## 1. 足元が自分の色になる(半紙に墨)

### 見た目・背景

- 床は半紙。歩いたマスに自分の色の墨が付く。
- 背景は書き初めの机(硯・文鎮・筆)。別案として子供部屋のお絵かき帳(画用紙にクレヨン)。

### 基本の仕組み

- 歩いたマスが自分の色になる。
- 自分の色の上では少し速くなる。相手の色の上の罰はなし。

### 元の案の問題

塗った面積が多い人ほど有利になり、さらに塗れる(雪だるま式に差が開く)。

### 懸念点と解決の例

| 懸念点 | 解決の例 |
|---|---|
| 復活した人は陣地がなく、頭だけで不利 | **打った積み木も通り道を塗る**。幽霊は積み木を打ち返せるので、幽霊の間も自分の色を増やせて、復活した時点で陣地がある |
| 同上 | **復活時に墨をこぼす**。出現地点のまわりが丸く自分の色になる |
| 勝っている人がどんどん有利になる | **墨は乾く**。塗ってから10秒ほどで薄くなって消える。陣地は「最近の足跡」だけになる |
| 積んで強い人がさらに強くなる | **身軽なほど筆が太い**。頭だけなら3マス幅、5段以上なら1マス幅。氷割りの「軽い人ほど跳べる」と同じ考え方 |
| 自分の陣地にこもる | 効果は「自分の色の上で少し速い」だけにして、相手の色の上の罰はなし。補給所は塗れない床にする |
| 床がうるさくて積み木が見えにくい | 墨は薄めの色にし、色に加えて模様(点・線・丸・波)でも区別する |
| ネット対戦の同期 | 変わったマスだけをホストから送る。マスは大きめ(1m前後)にして数を抑える |

### おすすめの組み合わせ

「打った積み木も塗る」「墨は乾く」「身軽なほど筆が太い」の3つ。
「打った積み木も塗る」は、ショットが一直線に墨の線を引くので、このゲームの基本操作と一番かみ合う。

### 未定

- マスの大きさ、乾くまでの秒数、速くなる割合。
- ステージの形。

## 2. TNT鬼(ねずみ花火)

### 見た目・背景

- 火種はねずみ花火(線香花火も候補)。持っている人の頭上で花火が燃える。
- 背景は夏の夜の縁側(蚊取り線香・バケツ・うちわ)。

### 基本の仕組み

- 火種を持つ人は、時間切れで爆発する。
- 火種は相手に移せる。

### 最初に誰に付けるか

- **一番高く積んでいる人に付く**(同数ならランダム)。勝っている人が狙われ役になり、復活直後の頭だけの人には付かない。**おすすめ。**
- 別案: 中央に花火が落ちてきて、最初に触れた人に付く。全員が避ければ誰にも付かないので弱い。

### どうやって移すか

- **火種を持つ人が、積み木かハンマーで相手にダメージを与えると移る**。既存の「手柄」の判定をそのまま使える。
- 積み木を持っていなくてもハンマーで直接移せるので、手詰まりにならない。
- 火種を持つ人は少し速くなる(ねずみ花火らしく走り回る)ので、追いかける側になれる。

### 時間切れでどうなるか

- **積み木が全部はじけ飛んで頭だけになる**。頭だけのときに爆発したら脱落。
- 即脱落より理不尽さが減り、飛び散った積み木が周りへの流れ弾になる。

### 懸念点と解決の例

| 懸念点 | 解決の例 |
|---|---|
| 爆発直前に移されて何もできない | 移った時点で残り時間が3秒未満なら3秒に戻す |
| 2人で移し合いが続く | 移した直後の1秒は、移し返されない |
| 復活直後に押し付けられる | 無敵の1.5秒は火種を受け取らない |
| 火種を持つ人が別の理由で脱落した | 火は消え、少し待って次の火種が一番高い人に付く |
| 幽霊の扱い | 幽霊は火種を持てず、移す対象にもならない |
| 残り時間が分からない | 頭上の花火が短くなり、音が速くなる。数字は出さない |

### 未定・確認すること

- 火種の秒数、次の火種が付くまでの待ち時間、速くなる割合。
- ステージの形。
- Shitaka さんの特殊ブロックに爆弾系がすでにあると役割がかぶるので、実装前に確認する。
