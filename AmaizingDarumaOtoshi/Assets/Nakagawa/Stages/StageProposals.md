## 1. 氷ステージ「氷割りゲーム」（名前は案）

元の案: クラッシュアイスゲームを参考に、六角形の氷の地面。ジャンプすると周囲の床にダメージが入り、一定回数で崩落する。中央に軸となる地面を置き、周囲を氷で囲む。薄い水色から黒に近づける。DebugStage09 か Stage03 を参考に、空いている所を氷で埋める。

- **見立て・背景**: ちゃぶ台の上のクラッシュアイスゲーム。背景は Chanoma。
- **地形**: Stage03（みかんの回転盆）の形を使い、回転台は外す。
  - 動かない床: 中央 14×14（軸）、四方の島 10×6、島と中央をつなぐ橋 3×3。
  - 氷: 上の床の間の空いている所を、六角形のタイル（向かい合う辺の間が約 2.4m、60〜70枚ほど）で埋める。
  - 壁は島の外側だけ（Stage03 と同じ）。氷の外は崖。
- **ギミック（新規・1種類）: 割れる氷**

| 項目 | 初期値 |
|---|---|
| ダメージの条件 | プレイヤーがジャンプして氷に着地したとき |
| ダメージの範囲 | 着地したタイルと、隣の6枚に1ずつ |
| 耐久 | 3 |
| 崩落 | 耐久0で1秒の予兆のあと落ちる。上の積み木とプレイヤーも落ちる |
| 復活 | なし |

- **色と予告**:
  - 白に近い薄い水色 → くすんだ青灰 → 暗い紺灰の3段階にし、ひびの模様も増やす。
  - 彩度は低くして、青い積み木と減速床の青緑にまぎれないようにする。
  - 真っ黒にはしない。崖や、持ち主のいない積み木の暗い輪郭と見分けられなくなるため。
  - 崩落の直前は、縁の黄色の点滅と小刻みな揺れで知らせる。
- **生成エリア（9か所）**: 中央の円（半径3）、島の角4か所（Stage03 と同じ）、対角の氷の上4か所（半径2）。
- **出現位置**: 四方の島（Stage03 と同じ）。
- **MaxBlocks**: 22。
- **狙う展開**: 序盤は氷の上の積み木を取り合う。軽い人ほど氷を割れるので、積んで重い人の足元を割って落とせる。後半は氷が減り、橋と中央に戦いが集まる。
- **注意点への対応**: 10個積んでも、橋を歩けば中央と島を行き来できる。
- **未決**:
  - 着地したタイル自身にもダメージを入れるか（上の表は入れる案。自分も落ちる危険が出る）。
  - 氷を復活させるか。
  - 飛んできた積み木でも氷が傷つくか（今は傷つかない案）。
- **要確認**:
  - ジャンプの着地を `DarumaCharacter.IsGrounded` で判定できるか。
  - 落ちたタイルの上に積み木が湧かないか（生成の処理）。

## 2. 麻雀卓「こたつの全自動卓」（名前は案）

元の案: 空から牌が降り、プレイヤーが触れると取得できる。殴ると、王冠のように手持ちのランダムな牌が落ちる。牌は3〜4種。1種を3つそろえるか、4種を1つずつ集めるとギミックを発動できる。イメージはスマブラのドラグーン、どこかが上がって牌が流れる、など。中央が空く。

- **見立て・背景**: お茶の間のこたつに置いた全自動麻雀卓。背景は Chanoma。
- **地形**: 26×26 の卓で、全周が縁（壁）。中央の 6×6 はふたで、ふだんは床。
- **ギミック（新規・1種類）: 牌あつめと洗牌**

| 項目 | 初期値 |
|---|---|
| 牌の種類 | 4種（「4種を1つずつ」の役のため、3種にはできない） |
| 牌が降る間隔 | 4秒に1枚。落ちる場所に予告の円を出す |
| 場に置ける牌 | 6枚まで。15秒で点滅して消える |
| 取得 | 生きているプレイヤーが触れると取る。牌に当たり判定とダメージはない |
| ドロップ | 攻撃を受けると、手持ちからランダムに1枚落ちる（王冠と同じ動き。0.7秒は拾えない） |
| 脱落したとき | 手持ちを全部落とす |
| 役 | 同じ牌3枚、または4種を1枚ずつ |
| 発動 | 役がそろうと自動。1.5秒の予告のあとに始まる |

- **発動の中身（案）: 洗牌**
  1. 画面上部に「○P ツモ！」と出し、中央のふたの縁が黄色く点滅する。
  2. ふたが開いて、中央が穴になる。
  3. 卓の上のプレイヤーと積み木が、4秒間、中央へ流される。発動した人だけは流されない。
  4. ふたが閉じ、4辺の縁の内側から積み木がせり上がって補充される。
- **色と見え方**:
  - 牌は白地に濃紺1色の図柄にし、種類は形で分ける（丸・棒・四角の枠・花）。文字と、赤・青・黄・緑は使わない。
  - 手持ちの牌は、画面下の各自の HUD パネルに並べる。頭の上には出さない。
  - 卓の布は彩度の低い緑にして、緑の積み木と明るさで差を付ける。
- **生成エリア（7か所）**: 四隅（半径2.5）、4辺の中央のうち3か所以上、ふたの上（閉じている間だけ湧く）。
- **出現位置**: 四隅から中央寄りの対称な4か所。
- **MaxBlocks**: 24。
- **狙う展開**: 牌を持っている人が狙われる。あと1枚の人を全員で殴って止めるか、落ちた牌を横取りするかの駆け引きになる。
- **注意点への対応**:
  - 全周が壁なので、落下はふたが開いている間だけ（意図して決めた形）。
  - 手持ちは最大6枚で、7枚目で必ず役ができるので、上限の処理は要らない。
- **未決**:
  - 「中央が空く」を、発動のときだけ開く形に読んだ。常に穴にする案もある。
  - 発動の中身（洗牌でよいか）。卓を傾ける案なら `BilliardTiltGimmick` が参考になりそう（中身は未確認）。
  - ドロップの条件は、ハンマーだけか、攻撃全般か（上の表は王冠と同じ攻撃全般）。
  - 発動を自動にするか、ボタンで撃たせるか（今は空いているボタンがない）。
- **実装の形**: HUD への表示と専用の物が多いので、Stage19・20 と同じく専用のビルダーにするのが合いそう。

## 3. 大会ステージ「決勝の特設ステージ」（名前は案）

元の案: スマブラの戦場。DebugStage61 を簡略化したイメージ。面積の広いせり上がり床を左右に2つ置き、交互に上昇と下降をさせる。

- **見立て・背景**: スタジアムの特設ステージ。背景は Stadium。
- **地形**: DebugStage61 から石柱と回転台を外した形。
  - `Arena(0, 0, 28, 20, 北=壁, 南=壁, 東=崖, 西=崖)`。
- **ギミック（既存・1種類）: せり上がり塀を広い床として使う**
  - `RisingWall(-6.5, 0, (8, 10), 0)` と `RisingWall(6.5, 0, (8, 10), 半周期)` で、左右が交互に上下する。
  - 既定の時間だと1周は 8.3秒（床3 → 予兆1 → 上昇0.5 → 壁3 → 下降0.8）なので、ずれは約 4.15秒。
  - 乗っている物は一緒に持ち上がる（既定の Lift）。高さは 1.5m。
- **色と予告**: 既存のままで足りる。待機中は床と同じ見た目で、予兆のときだけ縁が黄色く点滅する。新しい色は足さない。
- **生成エリア（7か所）**:
  - 中央の通路 `AreaRect(0, 0, 4, 8)`
  - 北と南の帯 `AreaRect(0, ±7.5, 10, 3)`
  - 左右の床の上 `AreaCircle(±6.5, 0, 2.5)`
  - 東西の端 `AreaRect(±12.25, 0, 3, 8)`
- **出現位置**: `(±9, ±7.5)` の4か所（床の上、崖から 5m）。
- **MaxBlocks**: 24。
- **狙う展開**: 上がっている側は高台と盾になり、下がっている側は見通しが開く。上がった床の側面で弾が跳ね返るので、中央の通路は跳弾が多くなる。東西の崖が落下の場所。
- **未決**:
  - 壁の向き（南北だけ壁の案。全周を崖にすると跳ね返りは床の側面だけになる）。
  - 上がっている時間を既定の3秒より長くするか。
- **要確認**:
  - 上がった床（1.5m）に下からジャンプで乗れるか。乗れないなら、上がる前に乗っていた人だけの高台になる。
  - `Ctx.RisingWall` で時間を変えられるか。

## 4. 部室「部室のサンドバッグ」（名前は案）

元の案: 中央に大きいサンドバッグを置き、殴ったら積み木が出る。他の積み木の生成レートを下げる。サンドバッグに耐久を付け、一定時間内に一定以上のダメージを与えたら破裂する。破裂したら、攻撃判定を持った積み木を6〜8個ほど拡散させる。耐久があると白、無くなるにつれ赤く点滅する。破裂後、一定時間でサンドバッグを復活させる。

- **見立て・背景**: だるま落とし部の部室。背景は Clubroom。
- **地形**: `Arena(0, 0, 26, 26, 全周が壁)`。中央にサンドバッグ（半径約 1.5m）を置き、積み木は壁と同じように跳ね返る。
- **ギミック（新規・1種類）: サンドバッグ**

| 項目 | 初期値 |
|---|---|
| 殴る | ハンマーが当たるたびに積み木が1個、殴った人の反対側へ出る（攻撃判定なし） |
| 出る間隔 | 0.4秒に1個まで。場の積み木が上限なら出ない |
| 色 | 既存の生成と同じ決め方（特定のキャラが得をしないように） |
| 蓄積 | 1発で+1。殴られないと 1.5秒ごとに-1 |
| 破裂 | 蓄積12で、0.8秒の予告のあと破裂する |
| 破裂の弾 | 攻撃判定のある積み木8個を、等間隔の8方向へ |
| 復活 | 10秒後。出る場所に予告の円を出し、上にいる物は外へ押し出す |

- **色と予告**:
  - 蓄積が少ない間は白。増えると点滅が速くなり、ふくらみ、揺れが大きくなる。
  - 破裂の予告の 0.8秒は、8方向に白い線を床に出す（砲台のガイドと同じ見せ方）。
  - 破裂の積み木は持ち主がいないので、`PlayerOutlines` の仕組みで暗い輪郭が自動で付く。
- **生成エリア（6か所。検証の下限）**: 四隅（半径2）、北と南の壁際の矩形。
- **出現位置**: 四隅から中央寄りの対称な4か所。
- **MaxBlocks**: 16前後。ふつうの生成を減らし、サンドバッグを主な供給元にする。
- **狙う展開**: 全員が中央に集まって殴り合う。積み木は殴った人の反対側に出るので、横取りが起きる。破裂が近づくと、殴り続けるか離れるかの読み合いになり、破裂の弾は壁で跳ね返って連鎖する。
- **未決**:
  - 点滅の色。元の案は「白 → 赤く点滅」だが、赤は 1P と赤い積み木の色で、`StageDesignPitfalls.md` の 1-1 に当たる。黄色の点滅（予兆の色）が候補。赤にするなら、`GimmickPalette` に「危険」の色を足すかを決める。
  - 幽霊が殴っても数えるか（今は数えない案）。
  - 飛んできた積み木が当たっても蓄積するか。
- **要確認**:
  - ハンマーがプレイヤー以外に当たったことを取れるか（`DarumaHammer.Hit` の中身）。
  - ステージごとに生成の間隔を変えられるか。
