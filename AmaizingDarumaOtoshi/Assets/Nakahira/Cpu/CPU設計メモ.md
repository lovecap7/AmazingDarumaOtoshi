## 1. 前提

- CPU は人と同じ操作命令（`DarumaCommand`：移動・ジャンプ・薙ぎ払い・股抜きショット）だけでキャラクターを動かす。ずるはしない。
- 相手が**どの積み木を狙っているかは分からない**（位置・動きから推測するだけ）。
- 相手の**積み木の数・ストック・持ち点は正しく分かる**（`MatchPlayer` の公開情報）。
- **有利・不利は積み木の数の差だけ**で決める。差 =「自分 − 相手」。
  - **差 ≥ +1 で有利**（遊んだ感触では、1段多ければ殴り合いで勝てる）。
- 相手が CPU か人かは区別しない。
- モード（ストック・タイム・ゴースト）では状態の組み立ては変えず、**点数の重みだけ**変える。
- 強さ（セレクト画面の CPU レベル 1〜9）は、CpuParams のアセットを分けて付ける。

### 目指す試合の雰囲気

- 段数の差が小さい（±2 以内）キャラ同士は、**直接殴り合って差がつくまで戦う**。
- 差が大きく開いたら（3 段以上）、少ない方は**逃げながら積み直す**。
- 積み木の取り合いでは、1 段でも多い方が強気に出て、少ない方は譲る。

## 2. 全体の構造

```
 ┌───────────── 知る（CpuPerception）─────────────┐
 │ 自分・相手・積み木・飛んでくる弾 を毎フレームまとめる │
 └──────────────────────┬──────────────────────┘
                        ↓
 ┌──────────── 決める（0.2秒ごと）────────────┐
 │ 各状態の「やりたさ」を点数にして一番高いものを選ぶ   │
 │ （切り替えには余裕を持たせて、ころころ変えない）     │
 │ 集中度（疲れ）が状態のしきい値を超えていたら移れない │
 └──────────────────────┬──────────────────────┘
                        ↓
   状態：  積む ／ 殴る ／ 撃つ（ついでに弾く）／ 逃げる ／ 攻めに行く ／ 待つ ／ 幽霊（自分が幽霊のとき。5.4）
                        ↓
 ┌──────────── とっさの反応（割り込み層）────────────┐
 │ 弾が来たら 打ち返す／踏んで拾う／よける を割り込ませる │
 │ 集中度（疲れ）が高いほど反応できる確率が下がる         │
 └──────────────────────┬──────────────────────┘

 集中度（認識の疲れ）：出来事のたびに足され、時間で減る。CPU ごとに1つ（4.1）
                        ↓

                        ↓
                  DarumaCommand
```

## 3. 知る（CpuPerception）

全状態が同じ情報を見る。毎フレーム（重いもの＝道の距離などは 0.2 秒ごと）まとめる。

| 対象 | 内容 |
|---|---|
| 自分 | 位置・積み木の数・接地・無敵・ハンマーを振っている最中か |
| 相手（1人ずつ） | 位置・**位置の変化から測った速度**・積み木の数・**段数の差（自分−相手）**・ストック・持ち点・生存/幽霊/復活待ち・無敵・ハンマーを振っている最中か・**自分からの道の距離**・奈落ぎわにいるか |
| 積み木 | 拾える積み木の一覧（今の `CpuCollect` の候補の探し方：道の距離・危ない場所の除外を移す） |
| 飛んでくる弾 | 攻撃判定のある積み木のうち、自分に当たりそうなもの（当たるまでの時間・何段目に当たるか・頭か） |

- 復活待ちの相手は数えない。
- **幽霊は攻撃の相手にはしない**（当たり判定がないので殴れない・弾も当たらない）。
- **幽霊は生存者にとって一番の脅威**として、逃げる理由に重く数える（5.3）。
- 距離の測り方：生存者は**道の距離**（歩いて来るので）、幽霊は**まっすぐの距離**（奈落の上も浮いて来るので）。

## 4. 決める（状態の選び方）

- 各状態が「やりたさ」の点数（0〜1）を出し、モード・強さの重みを掛けて、一番高い状態にする。
- **ころころ変えない**：今の状態に少し点数を足す（例 +0.1）。一度選んだら最低 0.5 秒は続ける。
- **集中度による止め**：集中度（疲れ）の割合が、移りたい状態の**しきい値**を超えていたら、その状態へは移れない。
  - 止めるのは「移る」ことだけ。今の状態を続けるのは自由。
  - 例：相手を首だけにした直後は疲れが大きい → 逃げるのしきい値を超えていて、大差の相手が近づいても逃げずに叩く。
- 状態が終わったとき（逃げ切った・狙った積み木を拾った等）は、**その時点の盤面で、移れる状態から選び直す**（どれも移れなければ積む）。

### 4.1 集中度（認識の疲れ）

2026-10-23 に定義を変えた（以前は「状態がその瞬間に出す値」だった）。

- CPU ごとに 1 つ持つ値。**出来事のたびに足され、時間で減る**（1 秒に 0.25）。
- 判定には「疲れ ÷ 容量」の**割合**を使う。**容量が大きいほど疲れにくい＝うまい CPU**（強さは主に容量で決める）。
- 使い道：
  1. **反応できる確率**：割合が高いほど、弾・相手の振りに反応できる確率が下がる（確率 × (1 − 割合)）。どの反応も選べる。
  2. **状態のしきい値**：割合がしきい値を超えていると、その状態へは移れない。

| 足す出来事 | 足す量 |
|---|---|
| 自分が相手を 1 段 → 0 段（首だけ）にした瞬間（あと一撃に夢中になる） | 0.95 |
| 弾に反応した（とっさの反応） | 0.3 |
| 相手の振りをかわした | 0.2 |
| 攻撃を受けて段が減った（焦る。自分の股抜きショットで減った分は除く） | 0.3 |

| 状態 | しきい値（割合） |
|---|---|
| 積む | なし（いつでも移れる） |
| 殴る | 0.9 |
| 逃げる（生存者から） | 0.6 |
| 逃げる（幽霊から。一番の脅威なので疲れていても気づきやすい） | 0.9 |

- 疲れの上限は容量の 1.5 倍（いつまでも回復しないことがないように）。復活したら 0 に戻る。
- 値はすべて CpuParams にあり、遊んで調整する。

### 状態ごとの点数の材料（案）

| 状態 | 上がる | 下がる |
|---|---|---|
| 積む | 自分の積み木が少ない・近くに拾える積み木がある・近くに相手がいない | 積み木が多い |
| 殴る | 近くに相手がいて段数の差が ±2 以内・有利・相手が首だけ・相手の空振り直後 | 相手が遠い・相手が無敵・自分が首だけ |
| 撃つ | 身の回りに積み木がない・段数に余裕がある・遠くに倒せそうな相手がいる・殴り合いから逃げた相手がいる | 自分の積み木が少ない（撃つと 1 段減る） |
| 弾く | （未設計） | |
| 逃げる | 近くの相手との差が −3 以下・自分が首だけ | 相手が遠い |

## 5. 状態

### 5.1 積む（今の CpuCollect を土台にする）

- 今の動き（道で迂回・跳んで拾う・回転台の先読み・バンパー回避）はそのまま。
- **取り合いの判断**
  1. 自分が狙っている積み木から **半径 2m 以内**に相手（生存者）がいるか調べる。
  2. いれば、その相手と段数を比べる（2人以上いれば、一番段数の多い相手と比べる）。
     - **有利（差 ≥ +1）→ 強気**：その積み木を取りに行く。
       相手の方が先に着きそうなら「殴る」の点数を上げる（取り合いから殴り合いへ）。
     - **不利（差 < 0）→ 譲る**：その積み木はやめて別の積み木を狙う。
     - **互角（差 = 0）→ 積み木に近い方が取る**。距離の差が 0.3m 未満なら、プレイヤー番号の小さい方が取る。
       （同じ段数の2人が同時に譲り合って、近づいては離れるのを繰り返さないように）
     - 別の積み木を選ぶときも、同じ判断で譲るべき積み木は避ける。
     - **譲った積み木は 3 秒狙わない**（相手が少し離れても、すぐ戻ってこないように）。
  3. 0.2 秒ごとに選び直すときにも、この判断をする（相手が後から近づいてきた場合）。
- **危険な相手を避ける**：積み木までの道が、危険な相手（幽霊・段数が 3 段以上多い生存者＝逃げる理由になる相手）から
  **5m 以内**を通るなら、その積み木は狙わない。
  - 逃げに入る距離（4m）より外側を通るので、「積み木を取りに行く → 逃げる → また同じ道で取りに行く」の繰り返しを防ぐ。
  - 今すでに 5m より近い相手からは「今より近づかない」道ならよい。
  - 一番短い道が危険なら、**中継点を経由する遠回りの道**を探す（例：橋が2本あれば反対側の橋から回る）。
    - 中継点の候補：自分の周り 12 方向 × 4・8・12m の、ナビメッシュ上の点。
    - 「自分 → 中継点」「中継点 → 積み木」の両方が危険な相手から 5m より離れていればよい。全体の長さで積み木を比べる。
    - 実際に歩くときも中継点に寄ってから積み木へ向かう（選ぶ道と歩く道を同じにする）。
    - 遠回りでも行けなければ、その積み木は狙わない。
- 何段まで集めるかは固定にしない。積み木が多いほど「積む」の点数が下がり、ほかの状態が選ばれるようにする。

### 5.2 攻め（3 つの状態に分ける）

このゲームの攻めは 3 種類あるので、状態も 3 つに分ける。**細かい条件は後で詰める**。

| 状態 | 攻め方 | 特徴 |
|---|---|---|
| **殴る** | 薙ぎ払いで相手を直接叩く | 当てると相手の最下段が抜けて弾になる。首だけの相手は脱落。近づく必要がある |
| **撃つ** | 股抜きショットで自分の最下段を撃つ | 遠くから攻められるが、**自分の積み木が 1 段減る**（有利・不利が動く）。地上でのみ |
| ~~弾く~~（状態としては作らない） | 落ちている積み木を薙ぎ払いで相手へ飛ばす | 回り込み・反射の計算が大変なわりに効果が小さいので、専用の状態はやめた。撃ち合いの最中に「ついでに弾く」だけ入れる（撃つの節） |

#### 殴る（詳細）

**薙ぎ払いの仕組み（設計の前提）**
- 届く距離：中心同士で約 2.5m（ハンマー 1.4m × HitReachScale 1.5 ＋ 体の半径）。正面の右 110° → 左 110° を 0.25 秒で振る。
- 当たる高さは相手の最下段だけ → 相手はジャンプでかわせる。自分が空中で振っても当たらない。
- 当てると相手の最下段が弾になって飛ぶ（首だけなら脱落）。ハンマーで相手は押されない。
- 振り終わるとすぐ次を振れる（硬直なし）。

**入る**
- 無敵でない生存者が道の距離 **3m 以内**にいて、段数の差が **−2 以上**（有利なら当然殴る）。
  - 差が −3 以下 → 逃げる（多くの場合、逃げは 4m の時点で先に始まっている）。
- 相手が複数いれば、狙う相手の点数（下の「狙う相手の選び方」）で選ぶ。

**中でやること**
1. **近づく**：道をたどって間合い（届く距離より少し内側。約 2.1m）まで近づく。相手の動きを少し先読みする。
2. **振る**：相手が間合いの中・自分の正面 ±90° 以内・相手も自分も地上（相手が跳んでいたら着地を待つ）なら振る。
3. **振る間隔**：振ったあと、次に振るまで **0.2〜0.6 秒**の間を置く（強さで変える。人がボタンを押す間隔に近づける）。
4. **相手の振りをかわす**：相手が振り始め、自分が相手の間合いにいたら**ジャンプでかわす**。
   着地したら、空振りした相手に**すぐ反撃**する（振る間隔を待たない）。かわす確率・反応の速さは強さで変える。
   - **反応は人並み（2026-11-06）**：人に遊んでもらったとき「最初のハンマーを確実にジャンプでかわされるのがストレス」という意見があった。
     前は 0.05 秒で跳んでいたが、人が見てから反応できるのは 0.2 秒くらい。DodgeReaction を つよい 0.2・ふつう 0.25・よわい 0.32 秒にした。
     ハンマーは 0.25 秒で右 +110° → 左 −110° を振り、正面の相手には約 0.12 秒で当たる（跳んでから当たらない高さまで約 0.05 秒）ので、
     見てからかわせるのは**左の端から来た振りだけ**（人と同じ条件）。ハンマーがもう自分の所を通り過ぎていたら跳ばない（当たってから跳ぶと間抜けに見えるため）。
   - **読みジャンプ（2026-11-06）**：相手が間合いにいて、自分が相手のハンマーの届く角度にいて、相手が地上でいつでも振れるときは、
     振られる前に先に跳ぶ（人も見てからではなく読んで跳んでいる）。
     - 相手が間合いに入った（入ってきた）瞬間：ReadJumpOnEnterChance（つよい 0.5・ふつう 0.3・よわい 0.15）で、0.05〜0.2 秒置いて跳ぶ。
     - 間合いにいる間：1 秒あたり ReadJumpRate（つよい 0.6・ふつう 0.4・よわい 0.2）× 正面にいるほど 1（45° 以内で 1、届く角度の端で 0）。
     - 跳んだら 1 秒は読みで跳ばない（跳ね続けないように）。確率には余裕（1 − 集中度の割合）を掛ける。
     - 跳んでいる最中に相手が振ったら、着地後すぐ反撃する。読みが外れると着地のすきを殴られる（人は「跳ばせてから着地を殴る」で崩せる）。
5. **回り込む（殴りながら移動）**：
   - 振る間隔を待つあいだ、間合いの中で**相手を自分の右側に置くように横へ動き続ける**（StrafeChance。振るたびに決める）。
     ハンマーは右から左へ振るので、右にいる相手にはすぐ当たる（右 45° なら約 0.07 秒）。相手は向き直り続けることになる。
   - 相手の振りをかわすジャンプの最中に、**相手の背中側（正面から 150°）へ移動**する（CircleChance）。
   - 振れる時なのに向きが合わなければ、相手を右前 45° に置く向きへ向き直してから振る。
   - 回る先に床がなければ反対向きに回る。
   - CPU 同士の対戦では有利にも不利にもならなかった（相手の CPU は一瞬で向き直り、0.05 秒でかわすため）。人は向き直り・反応が遅いので、人相手には効く見込み。
6. **殴りながら積む**：相手が振っていないときに、自分の**すぐそば（1.5m 以内）で、相手の間合いの外**にある積み木は跳んで拾う。
7. **少しだけ追う**：相手が逃げたら追うが、道の距離で **6m より離れる**か、**3 秒追っても間合いに入れなければ**やめる。

**終わる**（その時点の盤面で選び直す）
- 差が −3 以下になった（→ 逃げる）。
- 相手が離れた（上の「少しだけ追う」の条件）。
- 相手が幽霊・復活待ち・無敵になった。

**集中度**
- 自分の一撃で相手を **1 段 → 0 段**にした瞬間に +0.95（あと一撃に夢中になり、逃げ・弾への反応がしにくくなる）。
- 相手の振りをかわしたら +0.2。かわす確率は「かわす確率 × (1 − 集中度の割合)」。

**焦り（無意味だけど焦って操作してしまう）**
- 焦り（0〜1）＝ 集中度の割合が 0.4 を超えると上がり始め、割合 1 で最大。
- 焦っているほど：
  - **ハンマーを連打**する（振る間隔が 0.2〜0.6 秒 → 0〜0.05 秒へ）。
  - 振るたびに「焦り」の確率で**雑に振る番**になり、相手が跳んでいても・自分が跳んでいても・向きが合わなくても・
    届かない距離（＋1.5m まで）でも振ってしまう（空振り）。
  - **意味もなく跳ぶ**（最大 1 秒に 2.5 回）。
  - かわすジャンプが**遅れる**（最大 0.2 秒のずれ。間に合わないことがある）。
- 焦った操作では疲れを足さない（本当にかわしたときだけ足す）。
- テスト（止まった相手に 6 秒）：割合 0 → 振る 1.8 回/秒・空振り 1・無意味なジャンプ 0 ／ 割合 1.0 → 振る 3.0 回/秒・空振り 7・ジャンプ 9。
- 今は殴る状態だけ。

**相手の振りを知る方法**：キャラクターから「ハンマーを振っている最中か」を読む（画面に見えている情報なので、ずるではない）。
- ハンマーが実際に動き始めてから（物理が 1 ステップ進んでから）見えるようにする。ボタンを押したフレームに見えると、
  後から操作命令を読むキャラクターだけが 1 フレーム早く反応でき、CPU 同士の殴り合いが 10 勝 2 敗に偏った。

#### 撃つ（詳細）

実装：`CpuShotState`（2026-10-28）。股抜きショットで自分の最下段を撃ち出す（撃つと自分が 1 段減る）。

**撃つ理由（人の行動を 4 つの動機に分けた）**

| 動機 | 条件 | 距離 |
|---|---|---|
| **狙い撃ち**（基本） | 身の回り（5m）に拾える積み木がない／自分の段数が「残しておきたい段数」（4 段）より多い／狙える相手がいる（攻めの点数が一番高い相手） | 殴る間合い（3m）より遠く 8m 以内 |
| **熱中**（たまに） | 撃ち始めるたびに「熱中する確率（0.6）× 焦り」で熱中。熱中中は残しておきたい段数を無視し（首だけになるまで撃つこともある）、撃つ間隔も 0.3 秒に短くなる | 狙い撃ちと同じ |
| **追い撃ち**（特殊） | 殴り合いの相手が間合いの外へ逃げてから 3 秒の間。残しておきたい段数は無視するが、撃って首だけにはならない（2 段以上のとき） | 3m〜8m |
| **乱反射遊び**（たまに） | 拾いに行くには遠すぎる（歩く道がない・道の長さが 15m 以上）積み木の固まり（半径 2m に 3 個以上）へ、1 秒に 10% の確率で撃ち込む | 5m〜12m |

**撃ち方**
- **偏差撃ち**：相手の動き（位置の変化から測った速度）と、弾が届くまでの時間（振り始めから弾が出るまで約 0.2 秒＋飛ぶ時間）から当たる位置を予想する。
- **ばらつき**：撃つたびに ±ShotAimError（強い CPU：3°）の範囲でずれる。弱いほど大きくする。
  集中度の割合が上がるほど ShotAimErrorMax（9°）に近づく（焦ると連打で雑になる。2026-10-30）。
- 股抜きショットは押した瞬間にスティックの向きを向き、弾が出るまで追従するので、狙う向きへスティックを小さく倒して撃つ。
- 撃つ線上に壁があれば撃たない（壁での反射を狙った撃ち方はしない）。
- 撃つ間隔：落ち着いているときは 0.6〜1.2 秒。集中度の割合が上がるほど 0〜0.05 秒（ShotMashInterval。ショットの動作が終わればすぐ撃つ連打）に近づく。
  熱中中は 0.3 秒以下（2026-10-30。前は熱中しなければ常に 0.6〜1.2 秒で、撃った弾を見てしまう初心者のようだった）。
- **撃ちながら動く**（2026-10-30。前は棒立ちどうしで撃ち合っていた）
  - 撃ったあと、次に撃つまでの間は横へ走る（ShotStrafeChance 0.8。外れたらその場で止まって撃つ）。撃つたびに左右を選び直す。
    相手との距離を「殴る間合い +1m 〜 射程 −1m」に保ち、横に床がない・バンパーなら反対へ。撃つ瞬間にスティックの向きへ向き直るので、走っていても狙える。
  - 撃つボタンを押してから弾が出るまで（約 0.2 秒）は、スティックの向きが狙いになるので横へは動けない。
    ShotStepInChance（0.4）で相手の方へ踏み込みながら狙う（相手が殴る間合い +1.5m より遠いときだけ）。
  - 弾が出た直後の約 0.1 秒は、撃った本人にヒットストップ（時間 0.1 倍）がかかるので止まって見える（ゲームの仕様。人が操作しても同じ）。
  - 確認（DebugStage21・3 体 9 段・30 秒 × 2）：弾が出たあとは横へ秒速約 3.6m で走る。撃つ状態の間に止まっているのは、狙う間（踏み込まない番）・ヒットストップ・止まる番だけ。
    集中度 0.6〜0.7 で撃つ間隔 0.6〜0.7 秒、0 付近で 0.9〜1.5 秒。

**ついでに弾く**（「弾く」状態の代わり。2026-10-28）
- 撃ち合いの最中に、ハンマーの届く範囲（届く距離より 0.2m 内側）に落ちている積み木があり、
  それを弾けば相手に当たる向きなら、撃つより先に薙ぎ払いで弾く（自分の積み木が減らない）。
- ハンマーは積み木を「自分から見た積み木の方向」へ飛ばすので、その線の上を相手（動きを先読みした位置）が
  0.8m 以内で通るかを調べる。飛ばせる向きは正面の左右 60° まで。回り込み・壁での反射は考えない（たまたま向きが合ったときだけ）。
- 弾く確率 FlickChance（強い CPU 0.8。積み木ごとに一度だけ決める）。弾いたら集中度 +0.05。
- 身の回りの積み木を確かめるのは撃ち始めるときだけ。撃ち合いの最中に近くに落ちてきた積み木は弾く材料にし、
  弾けなかった積み木は撃ち合いが終わってから積むで拾う。
- テスト：相手への線上の積み木は弾いて命中。30° ずれ・横・後ろの積み木は弾かない。

**撃ったあと**：集中度 +0.05。そのあとは普通の状態選び（積み木が減れば積む、相手が近づけば殴るか検討、など）。打ち返された弾にはとっさの反応で対応する。

**点数**：撃つ 0.62（殴る 0.65 より低く、積む 0.5 ＋ 続けたいおまけ 0.1 より高い。遠くにしか積み木がないとき、積むから移れるように）。しきい値 0.8。

**テスト結果**
- 狙い撃ち（止まった相手・6.5m）：3 発撃って 3 発命中。4 段で撃つのをやめて積むへ。
- 偏差撃ち（7m 先を横切る相手・5.4m/秒）：8 発中 8 発命中（先読みしないと約 2m ずれる）。
- 追い撃ち：3 段（残しておきたい段数以下）でも撃ち、1 段で止まった。追い撃ちでなければ撃たない。
- 熱中（焦り最大）：首だけになるまで撃ち続けた。落ち着いていれば 4 段で止まる。
- 乱反射遊び：奈落の向こう（歩くと約 17m）の固まりへ撃ち込んだ（確率を上げてテスト）。

#### 狙う相手の選び方（3 つの攻めで共通）

生存している相手それぞれに点数を付け、**一番高い相手を狙う**。

| 要素 | 向き | 備考 |
|---|---|---|
| 相手の段数 | 少ないほど高い | 首だけ（0 段）は特に高い（一撃で倒せる） |
| 相手との距離（道の距離） | 近いほど高い | |
| ルールの重み | モードごと | ストック：残りストックが多い相手ほど高い／タイム：持ち点が多い相手ほど高い（トップを止める方が面白い）／ゴースト：（未決） |
| 無敵中 | 狙わない | 復活直後など |
| 幽霊 | 狙わない | 攻撃の判断材料にもしない |

- 重みは CpuParams にモードごとに置く。
- 狙う相手もころころ変えない（今の相手に少し点数を足す）。

### 5.3 逃げる

**入る条件**（どれか。追ってくる相手＝「追っ手」として覚える）
- 道の距離 **4m 以内**の生存者との**差が −3 以下**（相手の方が 3 段以上多い）。
- **幽霊**がまっすぐの距離 **4m 以内**にいる（段数に関係なく。一番の脅威なので、逃げたさも生存者より高い）。
- **1 段 → 0 段になった瞬間に 1 回だけ**、4m 以内の生存者との**差が −1 以下**（相手が 1 段でも多い）なら逃げる。
  - 0 段なら無条件で逃げるわけではない。「相手 1 段・自分 0 段」のように、通常の条件（差 −3）に引っかからない場面を救うための判定。
- ただし、集中度（疲れ）の割合が**しきい値（生存者から 0.6・幽霊から 0.9）を超えていると入らない**（殴り合いに夢中で逃げ遅れる）。

**中でやること**
- 追っ手から離れる場所（逃げ先）へ、道（ナビメッシュ）を使って逃げる。
  - 逃げ先の候補：自分の周り 12 方向 × 4・7・10m の、ナビメッシュ上の点。
  - 良い逃げ先：どの追っ手からも「今の自分より遠い」点のうち、追っ手から遠く、道が短い点。
- **※重要※ 逃げ道の途中にある積み木を、逃げながら拾う。**
  - 拾ってよい積み木：どの追っ手から見ても「今の自分より遠く」（寄り道しても追っ手に近づかない）、
    かつ「自分の方が追っ手より 1m 以上早く着く」積み木。その中で道が一番短いもの。
  - 取り合いの判断（5.1）も同じようにする。

**終わる条件**（追っ手がいなくなったら終わり。追っ手は次のどれかで外れる）
- 追っ手が **7m より遠く**なった（逃げ切った。入る距離より大きくして、出入りを繰り返さないようにする）。
- 生存者の追っ手との**差が 0 以上**になった（積み木を拾って追いついた）。
- 追っ手が復活待ちになった・幽霊から復活した（復活した相手は生存者として判断し直す）。

**終わったあと**：その時点の盤面で選び直す（反撃するか、積みに行くか）。

### 5.3.1 攻めに行く（2026-10-28）

盤面に積み木がなくなると CPU が立ち止まってしまうため追加した。実装：`CpuApproachState`。

- **入る**：盤面に拾える積み木が 1 つもない、または積み終わった（CollectUntil 段）。積むが優先なのは変えない（拾える積み木があるうちは選ばれない）。
- **中身**：攻めの点数（狙う相手の選び方）が一番高い相手へ、道をたどって近づくだけ。近づけば殴る（3m）・撃つ（8m）が点数で選ばれて引き継ぐ。
- **狙う相手**：自分が有利な（段数の差 ≥ 1）相手だけ（2026-10-28 変更）。幽霊・無敵中も狙わない。道が危険な相手のそばを通る相手も狙わない（近づいて逃げる、を繰り返さないように）。
  - 変更の理由：本番ステージでは積み木の供給が少なく、盤面が空の時間が 68〜94%。0 段どうしで突っ込み合い、首だけで倒し合っていた（平均段数ほぼ 0・撃つ 0 回）。
- **点数**：0.45（待つ 0.3 より高く、殴る・撃つ・逃げるより低い）。
- **テスト**：積み木なし・6 段どうしを奈落の両側に離して置く → 近づいて撃ち合い（6.6m）→ さらに近づいて殴り合い → 6.4 秒で決着。
  2 段と 7 段 → 7 段の方だけ攻めに行って撃ち、2 段の方は近づかれたら逃げた → 13.5 秒で決着。

### 5.3.3 遊ぶ（満タン近く、2026-10-30）

3 体で 15 分動かしたら全員 10 段（CollectUntil）になり、止まってしまった（攻めに行くは有利な相手だけ・待つは敵から離れる・乱反射遊びは歩いて行けない固まりだけ、のため）。
人は満タンになると積み木の固まりや相手に撃って遊ぶので、PlayfulStack（8 段）以上を「遊ぶ側」とし、次のように変える（`CpuContext.IsPlayful`）。

- **攻めに行く**：同じ段数の相手にも行く（差 ≥ 0）。点数はふだんと同じ 0.45（遊ぶ側では積むが 0.25 に下がるので、積むには勝つ）。
  - 2026-10-30 修正：最初は 0.55 にしていたが、今の状態に足す +0.1 で 0.65 になり、殴る（0.65）と同点・撃つ（0.62）より上になって引き継がれなかった。
    8 段の 3 体が攻めに行くのまま押し合い、塊になって回っていた。0.45 に戻し、さらに殴る距離（道の距離 3m）まで近づいた相手は攻めに行くの相手から外す（攻めに行くが終わって選び直す）。
- **積む**：点数を 0.25 に下げる（PlayfulCollectScore。攻めに行ける相手がいなければ積む）。
- **撃つ**：狙い撃ちは、近くに拾える積み木があっても撃つ。相手が優先で、相手がいなければ乱反射遊び。
- **乱反射遊び**：歩いて拾える固まりにも撃つ（道の長さの条件を外す）。距離は 3m（殴るの開始距離）〜12m、撃ちたくなる確率は 1 秒あたり 0.5（PlayfulScatterChancePerSecond）。
- 撃つと段数が減るので、8 段を切ると今までの慎重な動きに戻り、積み直す。
- **確認**：DebugStage21 で 3 体とも 10 段にして 30 秒 → 近づいて撃ち合い（11 発）・殴り合いになり、止まらなかった。
  本番ステージ（Stage01・05・09）では 8 段に届かないので、動きは変わらない。

### 5.3.2 待つ（2026-10-28）

攻めに行ける（有利な）相手がいないとき、積み木の供給を待つ。実装：`CpuWaitState`。

- **入る**：攻めに行くと同じ（盤面に拾える積み木がない・積み終わった）。点数 0.3（攻めに行くより低い）。
- **先回り**：供給の予告（`TumikiSpawnWarning`。出る約 1 秒前に床に出る印）が出たら、一番近い予告の 1.3m 手前へ向かう。
  予告の上には乗らない（積み木・キャラクターが乗っていると生成が取りやめになる）。取り合いで譲るべき予告・危険な相手のそばを通る予告は選ばない。
- **予告がないとき**：供給エリア（`TumikiSpawnArea`）のすぐ外で、近くの敵が少ない所で待つ（2026-10-28 変更。前は一番近いエリアの縁で棒立ちだった）。

  - 候補：各エリアの外周 8 方向 × 縁（体の半径 + 1m 外）から 0/2/4m の点。床があり、どのエリアの中でもなく、バンパーに近くない点。
  - 点数（小さいほど良い）：近くの敵の重み（WaitDangerRadius 10m 以内、近いほど重い。幽霊 1.5・自分より段数が多い 1.0・同じ 0.6・少ない 0.3）

  - 今の場所より 0.15 以上良い所があるときだけ移る。敵が近づけば自然に場所を変える（2 体が近い場所を目指すと、近づいた所で片方が別の場所へ移る）。

  - 確認（Stage01〜11 の 6 ステージ・各 25 秒）：待っている間に止まっている時間は 18〜38%、続けて止まるのは最長 2.2 秒（前は最長 6.8 秒）。

### 5.4 幽霊（自分が幽霊のとき）

実装：`CpuGhost`（2026-11-04）。`DarumaCpu.ReadCommand` で、体が幽霊のときは生存者の状態の代わりにこれで動かす。
目的は**生存者にダメージを与えて早く復活すること**だけ。幽霊は浮いているので奈落・床のギミックは無視してまっすぐ進む
（ステージの範囲内。壁（ReflectWall）には沿って滑る）。ナビメッシュは使わない。

動きは 3 つ（ThinkInterval ごとに選び直す）＋ 攻撃（毎フレーム、何よりも先）。

**攻撃（最優先）**
- 振れば当たる相手がいれば、どの動きの最中でも振る（ハンマーを振っていない間、毎フレーム確かめる）。
- 当たるかの見込み：相手の角度 → ハンマーがそこを通る時間（右 +110° から左 −110° へ 0.5 秒）→ その時の相手の位置、を 2 回繰り返す。
  相手も自分も今の動きのまま進むとみなす（振っている間も追いかけ続けるので、逃げる相手にも届く。向きは振っている間変わらない）。
- 届く距離（CharacterHitDistance）の GhostHitMargin（0.9）倍以内。ハンマーが遠い角度を通るほど控えめにする（最大 0.85 倍）。
- 高さが 0.5m 以上ずれている・ハンマーが通るまでに着地しない（空中の）相手は当たらないとみなす。無敵中の相手には振らない。

**近づく（狙う相手）**
- 生存者のうち**一番早く追いつけそうな相手**を狙う。複数の幽霊が同じ相手を狙ってもよい。
- 追いつく時間 ＝ （まっすぐの距離 − 1.5m）÷ 追いつく速さ。
  追いつく速さ ＝ 幽霊の速さ − 逃げる速さ（下限 GhostMinClosingSpeed 0.8m/秒）。
  逃げる速さ ＝ 今こちらから離れていく速さ と 相手の最高速度（積み木が多いほど遅い）を GhostEscapeWeight（0.5）で混ぜたもの。
- 無敵中の相手は +3 秒。今の相手は −1 秒（ころころ乗り換えない）。
- 回り込む：相手の今の動きのまま、着くころにいそうな場所へ向かう（先読みは 1.5 秒まで）。
- 壁に沿って滑っても進めなければ、しばらく（0.7 秒）横へよける（それでも進めなければ反対側へ）。

**ワープゲート（近道）**
- 追いつく時間に、ゲート経由（ゲートまで ＋ GhostWarpCost 1.2 秒 ＋ 出口から。行き先が抽選なら出口ごとの平均）も比べ、早ければ入る。
- 入るつもりのないゲートはよける（中にいたら外へ出る）。ワープで出てきてから 1 秒は次のワープを考えない
  （出口のゲートは離れるまで反応しないので）。ゲートの中に 1.5 秒いても送られなければあきらめる。

**弾いて当てる**
- 落ちている積み木（幽霊から 10m 以内・ハンマーが当たる高さ）を弾いて生存者に当てる。幽霊が弾いた積み木が当たっても復活できる。
- 弾いた積み木は 15m/秒で飛び、5m/秒² で減速して 10m/秒を下回ると当たらない（約 12m）。積み木から相手まで GhostBatRange（9m）以内だけ。
- 積み木は奈落の上では落ちるので、通り道に床がある（1m おきに下を調べる）ものだけ。
- 見込みの時間（弾く位置へ行く ＋ 振る ＋ 積み木が飛ぶ）× GhostBatPenalty（1.5。外れることもあるので）が、近づく時間より短ければ選ぶ。
- 弾く位置：飛ぶ時間の半分だけ相手の動きを先読みした位置と反対側、積み木から 1.3m。そばに着いたら弾く向きへゆっくり進んで向きをそろえる。
- 振る：幽霊から積み木への向き（＝弾く向き。正面から ±60° まで）と、積み木から相手への向きのずれが 8° 以内のとき。
- 4 秒で弾けなければあきらめる（その積み木は 3 秒使わない）。振ったあとも 3 秒使わない。

**確かめた結果（CpuTest、CPU 3 人、幽霊になる人がいなければ 1 人を落とす）**
- 260 秒で幽霊になったのが 66 回。幽霊でいた時間は中央値 2.0 秒・最長 10.4 秒。
  振った 84 回のうち、生存者に当たったのが 66 回（すべてダメージ）。
- 弾いて当てる：狭いステージでは近づく方が早いのでほとんど選ばない。
  GhostBatPenalty を 0.2 にして試すと、弾いた 10 回のうち積み木が相手に当たったのが 6 回（ダメージ 3 回）。
- ワープゲートを使う動きは、ゲートのあるステージ（AllStages の DebugStage24 など）でまだ確かめていない。

## 6. とっさの反応（割り込み層）

実装：`CpuReflex`（2026-10-28）。どの状態の最中でも、状態が出した操作のあとに割り込む。

**見つける**
- 攻撃判定のある弾が、減速しながら直進して 1 秒以内（攻撃判定がなくなる前）に自分の体に触れるなら「当たる弾」。
  - 自分は今の位置に留まるとみなす。毎フレーム計算し直す。壁での反射は考えない。
  - 自分に当たらないようになっている弾（撃った本人・打ち返した本人）・頭の上や足の下を通る弾は除く。
- **弾ごとに一度だけ**「反応するか・どれで反応するか」を決める。

**反応を決める**（確率はどれも「設定の確率 × 余裕（1 − 集中度の割合）」。落ち着いているほど難しい反応を選ぶ）
1. 反応するか：ReactChance（標準 1.0）。外れたら何もしない（気づかない）。
2. タイミングが難しい順に試し、間に合わない反応は飛ばす：
   - **ジャンプ乗り**（CatchChance 0.7）：落ちてくる途中で、弾が体を通り過ぎている間に足が弾の上面より下に来るように跳ぶ。被弾せずに 1 段積める。
   - **打ち返し**（ReturnChance 0.8）：ハンマーが弾の方向を通る瞬間に、弾がハンマーの届く距離にあるように振る。
     弾がハンマーの届く角度（正面の左右 105°）の外なら、**必要なだけ向きを変える**（狙いは考えない。返る向きは向いている向き）。
   - **ジャンプ避け**（残り全部）：弾が通り過ぎる間、足が弾の上面より上にあるように跳ぶ。
   - **跳びながら動く**（2026-10-28）：DodgeMoveChance（0.8）で、ジャンプ避けのときに跳びながら動く（外れたら真上に跳ぶ）。
     状態が動こうとしていた向きが弾の進路に対して横向き（70°〜110°）ならそのまま進み、そうでなければ進路から横へずれる。
     跳んでいる途中・着地点に床がない、またはバンパーに近い向きには動かない（`CpuDodgeMove`）。
     殴り合いのかわすジャンプも同じ確率で、回り込まない番は相手の横へずれるか少し下がる。
     テスト：弾のジャンプ避けで空中の移動は約 1.2〜1.5m（真上は 0.1m 前後）。弾に当たる・落ちることは増えなかった。
3. 反応すると決めたら集中度 +0.3。反応の最中は、状態が出したジャンプ・薙ぎ払いを止める（ジャンプ乗りは弾の通り道に留まる）。

**タイミングの計算で考えること**
- 気づいてから動けるまでの遅れ（ReflexReaction 0.05 秒）。気づくのは発射の次のフレーム。
- 操作命令が物理に反映されるのは次の物理ステップ（0.02 秒後）。ジャンプも 0.02 秒刻みで上がる。
- タイミングのずれ（ReflexTimingError ±0.01 秒）。

**テスト結果（止まった CPU に 5m・7.5m から 20・30m/秒で撃つ、各 16 発）**
- ジャンプ乗りを優先：4 発乗る・8 発避ける（間に合わないときは避けに切り替わる）・4 発被弾。
- 打ち返しを優先：5 発返す・8 発避ける・3 発被弾。
- 避けだけ：12 発避ける・4 発被弾。
- 被弾はすべて「5m から 30m/秒」（気づいた時点で 0.12 秒後に当たるので、反応が間に合わない）。

**強さ**：強い CPU を基準に作り、弱くするときは CatchChance・ReturnChance・ReactChance を下げる・ReflexReaction・ReflexTimingError を上げる。

**選ばない**

**テスト結果**（DebugStage21、つよい CPU 4 人（いわだる・へびだる・あかだる・あおだる）。テストから必殺技を直接発動。

## 6.2 自分の必殺技を撃つ（2026-11-09。まず撃てるかの確認）

実装：`CpuSpecial`（DarumaCpu が毎フレーム、知る のあと・決める の前に呼ぶ）。
- ゲージ（`SpecialGauge`）が満タンで、キャラごとの発動条件 `ShouldActivate` を満たしたら撃つ。**今はどのキャラも満たす（満タンになったらすぐ撃つ）**。
  キャラごとの撃ちどころ（撃つ場所まで行く・集中度が高いと撃たない など）は、あとで `ShouldActivate` と新しい状態に足す。
- 撃てない間（積み木 0 個・ハンマーを振っている など）は、必殺技側の `TryActivate` が断るので、撃てるまで毎フレーム試す。
- どのキャラも `ISpecialAbility.TryActivate()` を呼ぶ。へびだる・だるきんぐは `TryActivate` の中で CPU を断っていたので、
  ほかのキャラと同じく「人かどうか」の確認を Update のボタン入力の所へ移した（ゆるべさんのファイル。人の操作は変わらない）。
  だるきんぐの詠唱は CPU からは確定できないので、2 秒で自動完了する。向きは詠唱中の移動入力（今の状態の動き）で変わる。
- **時間が止まっている・遅くなっている間（Time.timeScale < DarumaMatch.PlaySpeed。カットイン・ヒットストップ・やられ演出）は撃たない**。
  カットインはキャラごとに別のスクリプトで、始まったときの時間の速さを覚えて終わりに戻すため、
  ほかのカットイン中に撃つと時間が 0 のまま戻らなくなる（実際に起きた。だるきんぐが詠唱中のまま止まった）。
  人が別のカットイン中に撃った場合も同じことが起きるはず（ゆるべさんに伝える）。
- テスト（DebugStage21、つよい CPU 4 人 × 2 試合。始まって 4 秒でゲージを満タンにする）：
  7 キャラすべて 1 回ずつ撃てた（いわだる・へびだる・あかだる・だるきんぐ・みだる・きだる・あおだる）。エラーなし。
  だるきんぐは 2 段のまま積み木を拾うとゲージがたまるので、16 秒後にはまた満タンになっていた。
  4 人のゲージを同時に満タンにしても（2 回）、時間は止まったままにならず、エクスカリバーも毎回最後まで撃てた。

**暗転返し（あおだる）**
- みだるのファンネルのカットイン（時間が止まっている間）に、自分に向かってくる弾（分裂弾の追う相手が自分）があれば、その暗転中に六腕を撃つ。

- そのために **カットインの不具合を直す**（中平が決めた。ゆるべさんのファイル）：今はカットインのスクリプト 7 つ（SpecialCutIn・Iwadaru・Hebidaru・DaruKing・Midaru・Kidaru・AodaruCutIn）と
  `IwaImpactHitStop` が、始まったときの timeScale を覚えて終わりに戻すので、重なると 0 のまま止まる。
  時間を止めている数を数える共通の仕組みにして、最後の 1 つが終わったときに元の速さへ戻すようにする。
  → 直したら、`CpuSpecial` の「時間が止まっている間は撃たない」も見直す。
- **カットインの修正は済み（2026-11-09）**：`Nakahira.TimeStop`（`Assets/Nakahira/Player/Scripts/TimeStop.cs`）。
  - 演出が `TimeStop.Begin(this, 速さ)`／`TimeStop.End(this)` を呼ぶ。止めている演出のうち一番遅い値を使い、最後の 1 つが終わったら戻す。

  - `CpuSpecial` の「時間が止まっている間は撃たない」はそのまま。暗転返しだけその前に判断する。

**あおだるの実装（2026-11-10。`CpuSpecial`）**：あおだるは「満タンですぐ撃つ」をやめ、次の 2 つのときだけ撃つ。
- **暗転返し**（中平が決めた条件）
  - みだるのファンネルのカットインが始まった最初のフレームで決める（時間が止まっているので、位置も状態も暗転する前のまま）。
  - 条件：暗転する前に、みだると**向き合っていた**とき。人は誰にファンネルが行くか分からないので、分かる場面だけにした。
    - みだると戦っていた（殴る・逃げる（追っ手）・撃つ・攻めに行くの相手がみだる）。
    - または、みだるが**明らかに近かった**：みだるが自分に一番近い敵で、みだるから見ても自分がほかの敵より BlackoutNearMargin（2m）以上近い。
  - 確率 BlackoutCounterChance × 余裕（1 − 集中度の割合）。暗転してから BlackoutCounterDelay 秒（止まらない時間）で撃つ。六腕のカットインはすぐに重ねて出る。
  - 強さ：つよい 0.6・0.3 秒／ふつう 0.35・0.6 秒／よわい 0.1・1.0 秒（全体に控えめ。中平が決めた）。
  - ファンネルを撃ったみだるは、分裂弾の `TumikiHoming.Shooter` から知る（ゆるべさんのファイルに読み取り用を足した）。
- **とっさの六腕**（暗転返しでないとき。ファンネル以外の弾も）
  - 自分に当たる弾が **2 発以上**あるとき。または**追い込まれている**とき（段数 ArmsPanicStack（1）以下 かつ 集中度の割合 ArmsPanicLoad（0.8）以上）に弾が 1 発でも来たとき。
  - 六腕は撃ってから 0.25 秒（出現）で効き始めるので、ArmsLeadTime（0.3 秒）＋反応の遅れより早く当たる弾は数えない。
  - 弾ごとに一度だけ決める。確率は ReactChance × 余裕（追い込まれているときは余裕を掛けない。必死なので）。反応の遅れ ReflexReaction のあとに撃つ。
  - 1 発で追い込まれていないときは、今までのとっさの反応（ジャンプ乗り・打ち返し・ジャンプ避け）のまま。
- テスト用：`CpuSpecial.LogDecisions = true` で、撃つと決めた理由を Console に出す。
- **確かめた結果**（DebugStage21・つよい CPU のみだる・あおだる・あかだる。返す確率をテスト用に 1 にした）
  - みだるの 3〜7m で向き合っていた → 3 回とも暗転中に六腕を撃った。時間も正しく戻った。
  - あおだるが遠く（約 11m）、みだるのそばにあかだるがいた → 返さなかった。
  - 弾 1 発（追い込まれていない）→ 六腕を撃たずにジャンプ避け。弾 2 発 → 六腕を撃ち、無傷（10 段のまま）。
  - 弾 1 発・1 段・集中度 1.0 → 六腕を撃った。
- **気になったこと（ゆるべさんの六腕の性能。CPU では直せない）**：みだるとの距離が 3m だと、暗転返しで六腕を出しても倒された。
  ファンネルは 20m/秒で 3m を約 0.15 秒で飛ぶが、六腕は時間が戻ってから 0.25 秒たたないと弾を返さない。人が暗転返ししても同じになるはず。

## 7.1 ギミックの扱い（2026-10-30）

ナビメッシュは試合の最初に一度だけ作る（重いので作り直さない）。動くギミックは焼き込まず、次のように扱う。

| ギミック | 扱い |
|---|---|
| せり上がり塀 | 焼き込まない。当たり判定がある間（せり上がり始め〜床に戻るまで）だけ `NavMeshObstacle` で切り抜く（`CpuGimmickObstacle`）。当たり判定より水平に 0.2m 広く切り抜く（塀と壁の間の、体がぎりぎり通る 1m の隙間を道にしない。押し合って引っかかっていた） |
| 扇風機 | 本体だけ同じく切り抜き、往復に合わせて動かす。風は避けない（縁で踏ん張るで対応） |
| 移動床 | 焼き込まない。乗って移動する（下記） |
| ワープゲート（2026-11-04） | プレイヤーを送るゲートの中は歩けないエリアにする（ふだんの道で間違って入らない）。歩いて行けない場所へはゲートを使う道を求める（下記） |
| シューターレーン・加速床・減速床 | 今は何もしない（気にせず通る） |
| 回転台 | 当たり判定が無いので何もしなくてよい |
| バンパー | 前から：周りを歩けないエリアにする |

**移動床に乗る**（`CpuMovingFloors` / `CpuRide`）

- 各地点のそばの床の上（ナビメッシュ）に「乗り場」を置く（ナビメッシュを作ったときに調べる）
- 歩いて行けない場所へは「乗り場まで歩く → 床が止まるのを待つ → 乗る → 別の地点で降りる → 歩く」道を求める。道の長さ＝歩く長さ＋運ばれる距離×1.5＋手間 4m
  - 道を聞くところ（積み木選び・相手の道の長さ・待つ場所など）はすべてこれを使うので、向こう岸の積み木や相手も狙う
- 乗り降りは状態の外の層（`CpuRide`。状態 → 乗り降り → 縁で踏ん張る → とっさの反応の順）。移動だけを置き換え、攻撃・ショットは状態のまま
  - 乗り場で待つ：床がその地点に止まるまで乗り場に立つ
  - 乗る：床が止まっていて乗りきれそうなら床の真ん中へ。乗り始めたら床が止まっている間は乗りきる
  - 乗っている：床が動いている間・この床で行く途中は真ん中に立つ
  - 降りる：床が止まったら、止まった地点の乗り場までまっすぐ歩く（床と島の継ぎ目で縁の確かめに止められて、乗ったまま運ばれていたため）
- 足場の確かめ（`CpuSensor.HasGround`）は移動床を足場とみなさない（床の上の積み木を狙って、床が動いたあと落ちていた）
- ジャンプ避けで移動床の上へは跳ばない。着地点の先 0.95m にも床があること
- 試した結果（DebugStage23、3 人、4 分）：島の行き来 17 回、落下 0 回、乗ったまま運ばれる 0 回

**ワープゲートを使う**（`CpuWarpGates` / `CpuRide`、2026-11-04）

- 各ゲートのそばの床の上に「入り口」を置き、出口＝同じグループの自分以外のプレイヤー用ゲート
- 歩いて行けない場所へは「入り口まで歩く → ゲートの真ん中へ入る → 出口から歩く」道を求める。移動床の道もあれば短い方を使う
  - 道の長さ＝入り口までの長さ＋ワープの手間 3m＋出口から目的地までの長さの平均（行き先は抽選なので。目的地へ行けない出口は外れの手間 20m で数える）
  - 出口が 1 つのゲート（2 つで 1 組）は行き先が決まっているので選ばれやすい。外れの島に出たら、そこからまた道を求め直す
- 入るのは乗り降りと同じ層（`CpuRide`）：入り口に着いたらゲートの真ん中へ歩く
  - ワープで出てきた直後（ゲートの中にいる）なら、まず入り口へ出る。ゲートの中にいたばかりなら入り口で 0.6 秒待つ（ゲートは出てきたものに、離れてしばらく反応しないため）
  - 入って 1.5 秒送られなければ（出口がふさがっているなど）入り口へ出直す
- 試した結果（DebugStage24、3 人、3 分）：島の移動 65 回、ゲートに入った回数 85 回、ゲートで止まったまま 0 回

## 決まったこと（2026-10-23）

| 項目 | 決定 |
|---|---|
| 有利の基準 | 積み木の数の差だけ。自分 − 相手 ≥ 1 で有利 |
| 取り合いの「近く」 | 狙っている積み木から半径 2m |
| 同じ段数の取り合い | 積み木に近い方が取る（ほぼ同じ距離なら番号の小さい方）。譲った積み木は 3 秒狙わない |
| 攻め | 殴る・撃つの 2 状態。弾くは状態にせず、撃ち合いの最中の「ついでに弾く」だけ（2026-10-28） |
| 逃げる条件 | 近くの相手との差が −3 以下、または自分が首だけ。集中度（疲れ）がしきい値を超えていると入らない |
| 逃げる中身 | 道中の積み木を拾いながら逃げる。逃げ切る or 差が縮むまで続け、終わったら選び直す |
| 狙う相手 | 相手の段数・距離・ルールの重みを総合した点数が一番高い相手 |
| CPU と人 | 区別しない |
| 幽霊（自分が幽霊のときの動き） | 攻撃（最優先）／一番早く追いつける相手へ近づく（ワープは近道として使う）／積み木を弾いて当てる（5.4） |
| 幽霊（相手の幽霊） | 攻撃の相手・判断材料にしない。逃げる理由としては一番重い |
| 実装の順番 | 下のとおり（逃げるを殴るより先に） |
| 逃げの距離 | 入る：4m（生存者は道の距離・幽霊はまっすぐの距離）／逃げ切り：7m |
| 逃げの終わり | 追っ手が 7m より遠くなる、または生存者の追っ手との差が 0 以上になる |
| 0 段のときの逃げ | 1 段 → 0 段になった瞬間に 1 回だけ、4m 以内の相手との差が −1 以下なら逃げる |
| 寄り道 | 寄り道しても追っ手に近づかない積み木だけ（提案どおり） |
| 殴り合いの開始 | 生存者が道の距離 3m 以内に来たら段数を見て決める（差 −2 以上なら殴る） |
| 首だけのときの殴り合い（2026-10-28） | 自分が 0 段なら、相手が背を向けている（相手のハンマーが届かない、正面の左右 110° より後ろ。体の太さの分広め）ときだけ殴りに行く。途中で振り向かれたら相手の間合い +1m の外まで離れてやめる（相手の振りはかわす） |
| 殴る：追いかけ | 少しだけ追う（道の距離 6m より離れる・3 秒間合いに入れない、でやめる） |
| 殴る：相手の振り | ジャンプでかわして、着地後すぐ反撃 |
| 殴る：振る間隔 | 強さで 0.2〜0.6 秒 |
| 殴る：積み木 | すぐそば（1.5m）で相手の間合いの外なら拾う |
| 攻めに行く | 盤面に積み木がない・積み終わったとき、有利な相手（差 ≥ 1）へ近づく（積むが優先のまま） |
| 遊ぶ（満タン近く） | 8 段以上なら、同じ段数の相手にも攻めに行き、積むより攻めを選ぶ。相手を優先して撃ち、近くの積み木の固まりにも撃ち込む |
| 待つ | 有利な相手がいなければ供給を待つ。予告が出たら先回り、なければ供給エリアのすぐ外で敵が少ない所（危険な相手ほど重く数える）。着いたら少しうろうろする |
| 撃つ | 狙い撃ち・熱中・追い撃ち・乱反射遊びの 4 動機。残しておきたい段数 4、距離 8m（追い撃ちは 3m から）、偏差撃ち＋強さでばらつき、撃ったら集中度 +0.05 |
| とっさの反応の優先 | ジャンプ乗り → 打ち返し → ジャンプ避け（難しい順）。落ち着いているほど難しい方を選ぶ |
| 打ち返しの向き | 必要最小限の回転（届く角度の中ならそのまま）。狙いは考えない |
| 強さの作り方 | 強い CPU を先に作り、制限をかけて弱くする（判断の間隔を伸ばす・ジャンプ乗りや打ち返しの確率を下げる） |
| 殴る：回り込み | 振っていない間は相手を右側に置いて横へ動き続け、振られたら跳びながら背中側へ回る。確率は強さで変える |
| 集中度（2026-10-23 に再定義） | 認識の疲れ。出来事（相手を首だけにした・弾に反応した・振りをかわした・攻撃を受けた）で足され、時間で減る。割合が高いほど反応できる確率が下がり、しきい値を超えた状態へは移れない。うまさは容量で決める |
| 積むと危険な相手 | 積み木までの道が危険な相手から 5m 以内を通るなら、中継点を経由して遠回りする。遠回りでも行けなければ狙わない |
| 必殺技の撃ちどころ（2026-11-09） | 積み木はためない。いわだる・へびだるは敵に近づいて撃つ（へびだるは追いかける）、あかだる・みだるは敵を狙う、だるきんぐは 2 人巻き込める向き（1 対 1 は 1 人）、きだるは攻めるとき、あおだるは弾が当たりそうなときと暗転返し。集中度が高いと見逃す。強さで遅れ・狙い・すぐ撃つ確率・暗転返しの確率を変える。だるきんぐは 2 段を越えて拾わない（6.2.1） |
| キャラごとの差分（2026-11-09） | 性格づけ（キャラごとの点数の差）は作らない。まず「相手の必殺技を知る」、次に「自分のキャラの性能（パッシブ・必殺技）を使う」 |
| 危ない場所（2026-11-09） | 隕石の予告円・毒沼・ビーム・エクスカリバーの線。気づく遅れは強さで変える。中にいたら出る・外なら入らない・道や相手選びで避ける。毒沼の中の相手（へびだる）とは殴り合わない。ビームは越えない壁として扱う（ジャンプで越えない）。**毒沼の反転は直さない（中から出ようとして中心へ向かってしまう）**（必殺技で CPU を確実に倒せる見返りにする）（6.1） |
