# CPU 設計メモ（叩き台）

最終更新: 2026-10-23
状態: **検討中**（「未決」の項目を決めてから実装する）

---

## 1. 前提

- CPU は人と同じ操作命令（`DarumaCommand`：移動・ジャンプ・薙ぎ払い・股抜きショット）だけでキャラクターを動かす。ずるはしない。
- 相手が**どの積み木を狙っているかは分からない**（位置・動きから推測するだけ）。
- 相手の**積み木の数は正しく分かる**。
- 有利・不利は**積み木の数だけ**で決める（差がいくつ以上なら有利、のしきい値を CpuParams に置く）。
- モード（ストック・タイム・ゴースト）では状態の組み立ては変えず、**点数の重みだけ**変える。
- 強さ（セレクト画面の CPU レベル 1〜9）は、CpuParams のアセットを分けて付ける。

## 2. 全体の構造

```
 ┌───────────── 知る（CpuPerception）─────────────┐
 │ 自分・相手・積み木・飛んでくる弾 を毎フレームまとめる │
 └──────────────────────┬──────────────────────┘
                        ↓
 ┌──────────── 決める（0.2秒ごと）────────────┐
 │ 各状態の「やりたさ」を点数にして一番高いものを選ぶ   │
 │ （切り替えには余裕を持たせて、ころころ変えない）     │
 └──────────────────────┬──────────────────────┘
                        ↓
   状態：  積む ／ 攻撃 ／ 逃げる ／ 幽霊
                        ↓ 「集中度」を出す
 ┌──────────── とっさの反応（割り込み層）────────────┐
 │ 弾が来たら 打ち返す／踏んで拾う／よける を割り込ませる │
 │ ただし 状態の集中度 が 危険度 より高ければ無視する     │
 └──────────────────────┬──────────────────────┘
                        ↓
 動きの部品：道をたどる・跳んで拾う・相手を向く・薙ぎ払いの間合い・ショットの狙い
                        ↓
                  DarumaCommand
```

## 3. 知る（CpuPerception）

全状態が同じ情報を見る。毎フレーム（重いものは 0.2 秒ごと）まとめる。

| 対象 | 内容 |
|---|---|
| 自分 | 位置・積み木の数・接地・無敵・ハンマーを振っている最中か |
| 相手（1人ずつ） | 位置・**位置の変化から測った速度**・積み木の数・生存/幽霊/復活待ち・無敵・ハンマーを振っている最中か・**自分からの道の距離**・奈落ぎわにいるか |
| 相手の狙いの推測 | 相手の進む向きの先にある積み木を「相手が狙っていそうな積み木」とする（直接は参照しない） |
| 積み木 | 今の `CpuCollect` の候補の探し方（道の距離・危ない場所の除外）を移す |
| 飛んでくる弾 | 攻撃判定のある積み木のうち、自分に当たりそうなもの（当たるまでの時間・当たる高さ＝何段目か・頭か） |

## 4. 決める（状態の選び方）

- 各状態が「やりたさ」の点数（0〜1）を出し、モード・強さの重みを掛けて、一番高い状態にする。
- **ころころ変えない**：今の状態に少し点数を足す（例 +0.1）。一度選んだら最低 0.5 秒は続ける。
- 例外：命の危険（首だけ・奈落ぎわで狙われている など）は即座に切り替える。

### 点数の材料（案）

| 状態 | 上がる | 下がる |
|---|---|---|
| 積む | 自分の積み木が少ない・近くに拾える積み木がある | 積み木が多い・近くに強い相手がいる |
| 攻撃 | 自分が有利・相手が近い・相手が首だけ（あと一撃）・相手のハンマーが空振り直後 | 自分が不利・相手が遠い・相手が無敵 |
| 逃げる | 自分が不利・自分が首だけ・相手が近い | 有利・相手が遠い |
| 幽霊 | 幽霊のときだけ（他は選ばない） | — |

## 5. 状態

### 5.1 積む（今の CpuCollect を土台にする）

- 今の動き（道で迂回・跳んで拾う・回転台の先読み・バンパー回避）はそのまま。
- **取り合いの判断（今回の要望）**
  1. 自分が狙っている積み木の近く（○m 以内）に相手がいる、または相手がその積み木へ向かっていそう。
  2. 自分と相手の積み木の数を比べる。
     - **有利**（自分 − 相手 ≥ しきい値）→ **強気**：その積み木を取りに行く。相手が先に着きそうなら「攻撃」の点数を上げる（取り合いから戦いへ）。
     - **互角・不利** → その積み木はやめて、相手から離れた積み木を狙う。
- 何段まで集めるか（CollectUntil）は、ほかの状態の点数との兼ね合いで決まるようにする（「10段になったら攻撃」ではなく「多いほど積むの点数が下がる」）。

### 5.2 攻撃（未設計）

- 狙う相手を選ぶ：道の距離・相手の積み木の数（少ない＝倒しやすい）・首だけか。
- 近ければ**薙ぎ払い**（間合いに入って振る）、離れていれば**股抜きショット**（地上で、相手の動きを先読みして撃つ）。
- 首だけの相手は最優先（一撃で脱落）。

### 5.3 逃げる（未設計）

- 相手から道の距離で離れる。奈落ぎわ・行き止まりは避ける。
- 逃げながら積み木を拾えるなら拾う（逃げると積むの両立）。

### 5.4 幽霊（未設計）

- 生存者を薙ぎ払いで叩けば復活できる。叩きやすい相手（首だけ・近い）へ向かう。
- 奈落の上も浮いて行けるので、道は使わず直進でよい。

## 6. とっさの反応（割り込み層）

- 飛んでくる弾ごとに**危険度**を出す：当たるまでの時間が短い・頭に当たる・自分の積み木が少ないほど高い。
- 今の状態が**集中度**を出す。例：攻撃中に、目の前の相手が首だけ（あと一撃）→ 集中度が高い。
- **危険度 > 集中度** のときだけ反応する → 「瀕死の相手が目の前なら弾を無視して叩きに行く」人間らしさ。
- 反応の種類：
  - **打ち返す**：薙ぎ払いの間合いに入ってくる弾。タイミングで先端・根元が変わる。
  - **踏んで拾う**：ジャンプで上から触れれば被弾せず積める（拾い得）。
  - **よける**：間に合わないときは弾の進む向きの横へ動く。
- 強さで変えるもの：気づくまでの遅れ（反応時間）・タイミングのずれ・反応する確率。

## 7. 動きの部品（状態が使い回す）

- 道をたどる（`CpuNavMesh` の道・曲がり角・奈落の手前で止まる）
- 跳んで拾う（落下中に触れる距離で跳ぶ・動く積み木の先読み）
- 相手を向く・薙ぎ払いの間合いに入る・股抜きショットの狙い（相手の先読み）
- よける（弾の進路から外れる）

## 8. 強さ（CPU レベル 1〜9）

| 弱い | 強い |
|---|---|
| 反応が遅い・狙いがぶれる | 反応が速い・狙いが正確 |
| 状態の判断がおおざっぱ（点数にゆらぎ） | 状況を見て切り替える |
| 弾にあまり反応しない | 打ち返し・踏んで拾うを狙う |

## 未決（次に決めること）

1. **取り合い**：「近く」は何 m か。有利のしきい値（積み木の差いくつ）。
2. **攻撃と積むの切り替え**：何段くらいあれば攻めに出るか（固定値か、相手との差か）。
3. **逃げる**：どんなときに逃げるか（首だけのとき／不利なとき／相手が近づいてきたとき）。逃げ切ったら積むに戻るか。
4. **狙う相手の選び方**：一番近い相手／一番倒しやすい相手／一番強い相手（トップを止める）。
5. **CPU 同士**：CPU 同士も普通に戦うか、人を優先して狙うか。
6. **幽霊**：今回まとめて作るか、後回しか。
7. **実装の順番**：下の案でよいか。

## 実装の順番（案）

1. 知る（CpuPerception）と動きの部品を作り、今の「積む」をその上に作り直す（動きは変えない）。
2. 決める（点数での状態選び）と、積むの取り合いの判断を入れる。
3. 攻撃（薙ぎ払い → 股抜きショット）。
4. とっさの反応（打ち返し・踏んで拾う・よける・集中度との比較）。
5. 逃げる。
6. 幽霊。
7. 強さ（レベル 1〜9 の CpuParams）と、セレクト画面の CPU を DarumaCpu に差し替え。
